# Mentala — Описание проекта

## Что это за проект?

**Mentala** — это мультиплатформенное приложение для психологической самопомощи на основе искусственного интеллекта. Проект предоставляет пользователям доступ к персональному AI-терапевту через текстовый и голосовой чат, а также визуальное взаимодействие с реалистичным 3D-аватаром.

## Для чего предназначен проект?

### Основная цель

Mentala решает проблему доступной и безопасной психологической поддержки для людей, которые:

- Испытывают тревожность, стресс или прокрастинацию
- Нуждаются в ежедневной поддержке и совете
- Ищут альтернативу традиционной терапии или дополнение к ней
- Хотят получить помощь в удобное время без записи к специалисту

### Ключевые возможности (реализовано)

1. **Чат с AI-терапевтом**

   - Текстовый чат с искусственным интеллектом
   - Голосовое взаимодействие (TTS/STT)
   - Поддержка русского и английского языков
   - Эмпатичные ответы, основанные на принципах когнитивно-поведенческой терапии

2. **3D-аватар**

   - Реалистичный 3D-аватар-терапевт
   - Живое видео во время сессий
   - Визуальное взаимодействие для более естественного общения

3. **Система уведомлений**

   - Персонализированные уведомления на основе AI
   - Готовые шаблоны уведомлений
   - Настройка частоты и времени получения
   - Поддержка кастомных текстов

4. **Система подписок**

   - Несколько тарифных планов (Basic, PRO, Premium, Custom)
   - Гибкая система оплаты
   - Пробный период для новых пользователей

5. **Безопасность и приватность**
   - История диалогов не сохраняется по умолчанию (opt-in)
   - Шифрование данных
   - Защита персональной информации

## Какие потребности покрывает проект?

### Психологическая поддержка

- **Доступность**: Приложение доступно 24/7, без необходимости записи к специалисту
- **Анонимность**: Пользователь может получить поддержку, не раскрывая личность
- **Низкий порог входа**: Не требуется предварительная подготовка или знания
- **Мягкий подход**: Поддержка без осуждения, с фокусом на эмпатию

### Ежедневная поддержка

- **Уведомления и напоминания**: Персонализированные напоминания и мотивационные сообщения
- **Визуальное взаимодействие**: 3D-аватар создаёт ощущение живого общения
- **Многоязычность**: Поддержка русского и английского языков

## Целевая аудитория

### Основные персоны

1. **Иван, 22–35 лет**

   - Проблема: Тревожность, прокрастинация
   - Потребность: "Карманный" коуч для ежедневной поддержки
   - Решение: Чат с ИИ, персонализированные уведомления, визуальное взаимодействие

2. **Мария, 25–45 лет**

   - Проблема: Стресс, эмоциональная поддержка
   - Потребность: Доступная психологическая помощь
   - Решение: AI-терапевт, настройка уведомлений под свои нужды

3. **Алексей, 30–50 лет**
   - Проблема: Профессиональное выгорание, нужна поддержка
   - Потребность: Структурированная помощь с визуальным взаимодействием
   - Решение: Чат с ИИ, 3D-аватар для более естественного общения

## Технические особенности

### Мультиплатформенность

- **Web**: Полнофункциональная веб-версия
- **iOS**: Нативное приложение через Capacitor (в разработке)
- **Android**: Нативное приложение через Capacitor (в разработке)

### Безопасность

- **Privacy by default**: История не сохраняется без явного согласия
- **Шифрование**: Данные зашифрованы "на диске" и в транзите
- **Минимизация PII**: Сбор только необходимых персональных данных

### Архитектура

- **Фронтенд**: Nuxt 4 + TypeScript + Pinia + TailwindCSS
- **Бэкенд**: Nitro (Node.js) + PostgreSQL + Drizzle ORM
- **API-first**: REST API с валидацией через Zod

## Монетизация

Проект использует модель подписок с несколькими тарифами:

- **Basic**: Бесплатный тариф с ограниченным функционалом (7 дней пробного периода с Premium-возможностями)
- **PRO**: Базовый платный тариф с неограниченным чатом
- **Premium**: Расширенный тариф с аватаром и приоритетной поддержкой
- **Custom**: Настраиваемый тариф с выбором количества минут и опций

## Текущий статус

Проект находится в стадии активной разработки MVP. Реализованы следующие функции:

- ✅ Онбординг и регистрация пользователей
- ✅ Чат с ИИ (текст и голос)
- ✅ 3D-аватар (базовая версия)
- ✅ Система подписок и биллинга
- ✅ Система уведомлений (AI и шаблоны)
- ✅ Профиль и настройки приватности
- ✅ Настройка уведомлений с кастомными текстами
