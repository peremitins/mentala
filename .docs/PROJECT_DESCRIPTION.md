## Краткое описание

**Mentala** — это мультиплатформенное приложение для психологической самопомощи и работы с привычками на основе искусственного интеллекта. Проект предоставляет пользователям доступ к персональному AI-терапевту через текстовый и голосовой чат, а также визуальное взаимодействие с реалистичным 3D-аватаром.

### Ключевые особенности

- 🤖 **AI-терапевт**: Персональная поддержка на основе ИИ (текст/голос)
- 👤 **3D-аватар**: Реалистичная визуализация помощника для более естественного общения
- 📊 **Привычки**: Каталог привычек и настройка персонализированных уведомлений
- 🔔 **Персонализированные уведомления**: AI-генерированные напоминания и мотивационные сообщения
- 🌐 **Мультиплатформенность**: Web/PWA/iOS/Android через Capacitor
- 🔒 **Безопасность по умолчанию**: Privacy by default, история не сохраняется без согласия
- 🌍 **Многоязычность**: Поддержка русского и английского языков

## Проблема и решение

### Проблема

Многие люди испытывают потребность в психологической поддержке, но сталкиваются с барьерами:

- **Недоступность**: Высокая стоимость традиционной терапии, длительное ожидание записи
- **Стигматизация**: Страх осуждения или нежелание раскрывать личные проблемы
- **Временные ограничения**: Невозможность получить помощь в нужный момент
- **Низкий порог входа**: Необходимость подготовки и предварительных знаний
- **Отсутствие ежедневной поддержки**: Потребность в постоянном сопровождении, а не только разовых сессиях

### Решение Mentala

Mentala решает эти проблемы, предоставляя:

- **Доступность 24/7**: Приложение доступно в любое время без необходимости записи к специалисту
- **Анонимность**: Пользователь может получить поддержку, не раскрывая личность
- **Низкий порог входа**: Не требуется предварительная подготовка или знания
- **Мягкий подход**: Поддержка без осуждения, с фокусом на эмпатию
- **Ежедневное сопровождение**: Персонализированные уведомления, напоминания и мотивационные сообщения
- **Визуальное взаимодействие**: 3D-аватар создаёт ощущение живого общения

## Основные функции

### 1. Чат с AI-терапевтом

- **Текстовый чат**: Интерактивное общение с искусственным интеллектом
- **Голосовое взаимодействие**: Поддержка Text-to-Speech (TTS) и Speech-to-Text (STT)
- **Эмпатичные ответы**: Основанные на принципах когнитивно-поведенческой терапии (КПТ)
- **Многоязычность**: Поддержка русского и английского языков
- **Безопасность**: Фильтрация запросов высокого риска с перенаправлением на ресурсы помощи

### 2. 3D-аватар

- **Реалистичная визуализация**: Живое видео во время сессий
- **Визуальное взаимодействие**: Синхронизация губ, анимации (мигание, кивок)
- **Интеграция с чатом**: Аватар реагирует на диалог в реальном времени
- **Технология**: LiveKit для стриминга видео и аудио

### 3. Система уведомлений

- **AI-генерация текстов**: Автоматическое создание персонализированных сообщений
- **Готовые шаблоны**: Библиотека предустановленных уведомлений
- **Гибкая настройка**: Выбор дней недели, временных интервалов, частоты
- **Кастомные тексты**: Возможность создания собственных сообщений
- **Три режима генерации**:
  - `templates` — использование готовых шаблонов
  - `ai` — AI-генерированные тексты (Buffer Pool из 50 текстов)
  - `hybrid` — комбинация шаблонов и AI

### 4. Привычки

- **Каталог привычек**: Предустановленный набор популярных привычек
- **Пользовательские привычки**: Создание собственных привычек с настройкой
- **Уведомления**: Персонализированные напоминания по привычкам

### 5. Терапия и темы

- **Каталог тем**: Предустановленные темы для работы (стресс, тревожность, выгорание)
- **Пользовательские темы**: Создание собственных тем терапии
- **Сессии**: Отслеживание времени терапии и прогресса
- **Интеграция с уведомлениями**: Настройка напоминаний по темам

### 6. Система подписок и биллинг

- **Тарифные планы**:

  - **Basic**: Бесплатный тариф с ограниченным функционалом (7 дней пробного периода с Premium-возможностями)
  - **PRO**: Базовый платный тариф с неограниченным чатом
  - **Premium**: Расширенный тариф с аватаром и приоритетной поддержкой
  - **Custom**: Настраиваемый тариф с выбором количества минут и опций

- **Учёт минут**: Система отслеживания использования минут с недельными лимитами
- **Пробный период**: 7 дней Premium-функций для новых пользователей
- **Биллинг-кредит**: Система кредитов при изменении тарифов
- **Интеграция с YooKassa**: Обработка платежей через российский платёжный шлюз

### 7. Профиль и настройки

- **Настройки приватности**: Управление сохранением истории диалогов (opt-in)
- **Экспорт данных**: Возможность экспорта всех персональных данных
- **Удаление аккаунта**: Безопасное удаление всех данных пользователя
- **Языковые настройки**: Выбор языка интерфейса (RU/EN)
- **Настройки уведомлений**: Детальная конфигурация времени и частоты

### 8. SOS-экран

- **Горячие линии**: Быстрый доступ к экстренным службам
- **Шаги самопомощи**: Структурированные инструкции для кризисных ситуаций
- **Ресурсы помощи**: Список организаций и сервисов поддержки
- **Перенаправление**: Автоматическое перенаправление при обнаружении запросов высокого риска

- **Проблема**: Тревожность, прокрастинация

## Архитектура системы

### Общий обзор

Проект использует архитектуру **Backend-for-Frontend (BFF)** на Nitro, который служит единой точкой входа для всех клиентов (Web/PWA/iOS/Android). В будущем возможно вынесение отдельных подсистем (например, биллинг) на отдельные сервисы.

### Структура фронтенда

```
app/
├─ components/          # Атомы/молекулы/организмы (поверх shadcn)
├─ composables/         # use* composables (запросы, helpers, vueuse)
├─ layouts/             # default, blank, auth
├─ middleware/          # auth, i18n-redirect
├─ pages/               # Маршруты приложения
│  ├─ index.vue         # Главный экран (аватар + чат)
│  ├─ onboarding.vue    # Онбординг
│  ├─ chat.vue          # Чат (fullscreen)
│  ├─ therapy.vue       # Терапия
│  ├─ habits.vue        # Привычки
│  ├─ settings.vue      # Настройки
│  ├─ subscription.vue  # Подписки
│  └─ profile/          # Профиль пользователя
├─ plugins/             # Автоподключение (i18n, vue-query, sentry)
├─ stores/              # Pinia stores (auth, user, chat, subscription)
└─ utils/               # Утилиты
```

### Структура бэкенда

```
server/
├─ config/              # Конфигурация (env, keys)
├─ domain/              # Бизнес-логика (сущности)
├─ ports/               # Контракты интерфейсов
├─ application/         # Сервисы и use-cases
│  ├─ subscriptions/    # Логика подписок
│  ├─ notifications/    # Логика уведомлений
│  └─ llm.service.ts    # Работа с AI
├─ infrastructure/      # Доступ к БД и внешним сервисам
│  ├─ db/               # Drizzle ORM схемы и миграции
│  ├─ llm/              # OpenAI адаптеры
│  └─ redis/            # Redis клиент
├─ interface/           # REST API и webhooks
│  ├─ api/              # API endpoints
│  └─ webhooks/         # Webhook handlers
└─ middleware/          # cors, helmet, rate-limit, request-id
```

### База данных

- **СУБД**: PostgreSQL
- **Конвенции**: snake_case для таблиц и полей
- **Primary Keys**: BIGINT AUTO INCREMENT (совместимость с Laravel)
- **ORM**: Drizzle ORM
- **Миграции**: SQL файлы (для совместимости с будущими системами)

**Основные таблицы**:

- `users` — пользователи
- `user_subscriptions` — подписки пользователей
- `subscription_plans` — тарифные планы
- `therapy_sessions` — сессии терапии (учёт минут)
- `payments` — платежи (YooKassa)
- `idempotency_keys` — ключи идемпотентности
- `notification_preferences` — настройки уведомлений
- `notification_texts` — тексты уведомлений
- `ai_generated_notification_texts` — AI-генерированные тексты
- `user_habits` — пользовательские привычки
- `therapy_topics_custom` — пользовательские темы терапии

### API конвенции

- **Base**: `/api/*`, JSON
- **Версионирование**: Через заголовок `X-API-Version: 1` (по мере роста `/api/v1/*`)
- **Аутентификация**: `Authorization: Bearer <jwt>`
- **Ошибки**: `{ "error": { "code": "E_xxx", "message": "..." } }`
- **Пагинация**: `?page=1&limit=20` → `{ items, page, limit, total }`
- **Идемпотентность**: `Idempotency-Key` на чувствительных POST
- **DTO**: Zod схемы в `shared/dto/*` (общие для фронтенда и бэкенда)

### Очереди и фоновые задачи

- **Брокер**: Redis (локально через Docker, в production через Upstash)
- **Очереди**: BullMQ 5.x
- **Основные очереди**:
  - `notification-slots-generation` — генерация слотов уведомлений
  - `notification-delivery` — отправка уведомлений через FCM
  - `ai-text-pool-refill` — пополнение пула AI-генерированных текстов
- **Retry**: 3 попытки с exponential backoff
- **Graceful shutdown**: Корректное завершение всех воркеров

## Безопасность и приватность

### Принципы безопасности

- **Privacy by default**: История диалогов **не** сохраняется без явного согласия пользователя
- **Zero-Access архитектура**: Сотрудники компании и администраторы не имеют доступа к пользовательским данным
- **End-to-End шифрование**: Сообщения шифруются перед отправкой (планируется)
- **Минимизация PII**: Сбор только необходимых персональных данных

### Реализация

1. **Хранение данных**: Шифрование "на диске" и в транзите
2. **История**: По умолчанию не сохраняется (opt-in), гибкие retention-периоды
3. **Метаданные**: Отдельное хранение метаданных без содержания сообщений (при saveHistory=false)
4. **Ключи**: Разделение ключей шифрования (как в Telegram)
5. **Регион хранения**: Данные хранятся в регионе (соответствие требованиям)

### Safety by design

- **Фильтрация запросов**: Обнаружение запросов высокого риска (самоповреждения, кризис)
- **Перенаправление**: Автоматическое перенаправление на SOS и ресурсы помощи
- **Контент-модерация**: Списки стоп-слов, эвристики, rate-limit
- **Аудит**: Журнал действий без содержания сообщений (при opted-out)

### Аутентификация и авторизация

- **JWT**: Access и refresh токены
- **Ротация токенов**: Автоматическая ротация refresh-токенов
- **CORS**: Ограничение доверенных origin
- **Rate limiting**: Защита от DDoS (per IP/user)
- **CSRF защита**: Планируется (см. auth_security_improvements_tz.md)

### Возрастные ограничения

- **Минимальный возраст**: 16+ (или согласно локальному праву)
- **Родительское согласие**: При необходимости для несовершеннолетних
- **Ограниченный контент**: Специальные настройки для подростков
