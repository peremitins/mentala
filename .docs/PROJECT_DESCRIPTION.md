# Mentala — Полное описание продукта

## Что такое Mentala

Mentala — мобильное и веб-приложение для психологической самопомощи на основе искусственного интеллекта. Продукт помогает пользователям справляться с тревогой, стрессом, нарушениями сна, вредными привычками и эмоциональными трудностями через персонализированный AI-чат, дыхательные практики, медитации и дневник благодарности.

Приложение работает как AI-терапевт в кармане: доступно 24/7, общается в текстовом и голосовом формате, помнит историю разговоров и адаптирует стиль общения под пользователя.

**Платформы:** Android (Google Play), Web (PWA) — доступны сейчас; iOS (App Store) — в разработке  
**Язык:** Русский и английский  
**Целевая аудитория:** 16+, пользователи, испытывающие стресс, тревогу, проблемы со сном, или желающие работать над вредными привычками

> **Текущая доступность платформ:**  
> - **Android** — приложение опубликовано в Google Play  
> - **Web / PWA** — доступно на всех устройствах через браузер; пользователи iOS могут установить PWA на экран «Домой»  
> - **iOS (App Store)** — приложение технически готово, но публикация в App Store в ближайшее время невозможна по ряду ограничений

## Пользовательский путь (Onboarding)

При первом входе пользователь проходит онбординг, после чего сразу получает доступ к 7-дневному Premium-пробному периоду без ввода платёжных данных.

### Шаги онбординга:

1. **Имя** — персонализация обращения
2. **Выбор тем** (до 5) — из двух категорий:
   - *Эмоциональное состояние и терапия:* тревога, стресс, депрессия, самооценка, одиночество, страхи, отношения, выгорание, сон и др.
   - *Привычки:* формирование полезных (спорт, режим сна, медитация, питание) и отказ от вредных (алкоголь, курение, переедание, соцсети и др.)
3. **Уведомления** — предложение включить персональные напоминания по выбранным темам (не обязательно)
4. **Возраст** — для адаптации контента
5. **Пол** — для персонализации
6. **Тон общения** — gentle / balanced / uplifting / direct

После онбординга пользователь попадает на главный экран приложения с активным 7-дневным Premium-доступом.

## Функциональность приложения

### 1. AI-чат (основная фича)

Персональный AI-терапевт, доступный в любое время.

**Возможности:**
- Текстовый чат на русском и английском
- Голосовой ввод (диктовка) и озвучивание ответов (TTS)
- Трёхслойная память:
  - *Сессионная память* — контекст текущего разговора
  - *Handoff-резюме* — краткое саммари предыдущей сессии для плавного продолжения
  - *Устойчивый профиль* — долгосрочные факты о пользователе (имя, цели, предпочтения)
- Персонализированный стиль ответов (тон, обращение)
- Кризисный протокол: автоматическое определение кризисных состояний с переключением в режим поддержки и показом контактов экстренной помощи
- Suggested chips — умные подсказки тем для продолжения диалога

**Лимиты по тарифам:**
- Basic: AI-чат недоступен
- PRO: 100 минут в неделю
- Premium: 900 минут в неделю (fair-use)

### 2. Итоги сессий

После AI-беседы пользователь может получить текстовое резюме разговора. Формируется двумя способами:
- **Вручную:** пользователь нажимает кнопку «Подвести итог» внутри чата
- **Автоматически:** один раз в сутки сервер обрабатывает незавершённые сессии в фоне

Итог включает ключевые темы, паттерны и рекомендации. После готовности пользователю приходит пуш-уведомление, история итогов хранится в разделе «Итоги сессий».

### 3. Медитации

Библиотека медитаций с аудио-треками и фоновыми звуками.

**Возможности:**
- Каталог медитаций с фильтрацией
- Аудиоплеер с loop-режимом для фоновых звуков
- Таймер с автоматической остановкой (работает при заблокированном экране)
- Избранные медитации
- Фоновые звуки/сцены (звуки природы, белый шум и др.) — работают параллельно с медитацией или самостоятельно
- Системный медиаплеер (управление с экрана блокировки / AirPods)

### 4. Дыхательные практики

Структурированные дыхательные упражнения с анимацией и голосовыми подсказками.

**Возможности:**
- Каталог практик (4-7-8, Box breathing, активирующие и расслабляющие)
- Анимированный визуальный гид по фазам
- Голосовые подсказки фаз (мужской/женский голос)
- Создание кастомных практик (1–30 сек на фазу, 2–4 фазы)
- Таймер с поддержкой фона / заблокированного экрана

### 5. Быстрая помощь (SOS)

Экран мгновенной поддержки при сильном стрессе или тревоге.

**5 техник:**
- 5-4-3-2-1 (техника заземления)
- Дыхание (быстрый сброс напряжения)
- Сброс напряжения в теле (с голосовыми инструкциями)
- Выговориться (свободный текстовый вход с возможностью перенести в чат)
- Выгрузка мыслей (речевой ввод + сохранение в чат)

### 6. Дневник благодарности

Ежедневный дневник для работы с позитивным мышлением.

**Возможности:**
- Ежедневные вопросы/подсказки из каталога (или кастомные)
- Избранные подсказки (до 50)
- Загрузка фото к записям (Premium)
- Streak (серия дней), timezone-aware
- История записей

### 7. Персональные напоминания

Система персональных поддерживающих уведомлений по выбранным темам (не трекер задач, а поддерживающие сообщения).

**Возможности:**
- Настройка расписания по каждой теме (дни недели, временной диапазон, до 5 слотов в день)
- Два режима контента уведомлений:
  - *Шаблонные* (Basic) — готовые поддерживающие тексты
  - *AI-генерируемые* (PRO+) — персональные тексты, созданные AI под конкретного пользователя с учётом тона и целей
- Пользовательское пожелание для AI-уведомлений
- Push-уведомления на iOS, Android, Web (PWA)

## Безопасность и приватность

- Кризисный протокол: автоматическое определение суицидальных/кризисных запросов, переключение на безопасный режим с контактами помощи
- История разговоров не сохраняется без согласия пользователя (Privacy by default)
- Шифрование данных в транзите и на диске
- Локальная защита входа: PIN-код + биометрия (FaceID / TouchID / отпечаток пальца)
- Минимизация персональных данных (PII)
- Соответствие возрастным ограничениям (16+)

## Финансовая модель

### Тарифные планы

| Тариф | Цена | AI-чат | Уведомления | Дополнительно |
|-------|------|--------|-------------|---------------|
| **Basic** | 0 ₽/мес | Недоступен | Только шаблонные | SOS, 2 дыхательные практики |
| **PRO** | 399 ₽/мес | 100 мин/нед | + AI-уведомления | Полная библиотека медитаций |
| **Premium** | 899 ₽/мес | ~900 мин/нед | + Персональный стиль | + Кастомные практики, фото в дневнике |

### Пробный период (Trial)

- 7 дней полного Premium-доступа при регистрации
- Без ввода платёжных данных
- Один trial на аккаунт (защита от злоупотреблений по email-хэшу)
- По окончании trial — автоматический откат в Basic (без скрытых списаний)

### Платёжные системы

- **Web:** YooKassa (оплата картой, автоплатёж, привязка карты)
- **iOS:** StoreKit 2 (Apple In-App Purchases)
- **Android:** YooKassa через внешний браузер

### Реферальная программа

- Пользователь получает реферальную ссылку
- Реферал получает скидку на первую платную подписку
- Реферер получает кредиты (billing credits) после оплаты реферала
- Промокоды: дополнительные дни доступа или скидки

### Механика удержания

- Серии (streak) в дневнике благодарности
- Персональные AI-уведомления
- Итоги сессий с пуш-напоминанием
- Re-engagement push: через 36 часов, 72 часа и 7 дней неактивности

### Планируемая retention-итерация

Следующая продуктовая итерация должна не добавлять отдельную новую фичу ради фичи, а перестроить вход в приложение вокруг ежедневного сценария:

- AI-чат остаётся первым и главным CTA на главном экране.
- Под AI-чатом появляется Mood Check-in как действие на 3–5 секунд.
- Карточка текущего шага и горизонтальная «Карта пути» объединяются в один блок: верхняя часть показывает активный шаг и кнопку «Начать», нижняя часть показывает скролл шагов. Кнопка и активный кружок запускают одно и то же действие.
- Под «Картой пути» остаётся «Мысль дня»: короткая персональная insight-карточка с fallback на шаблон и сохранением в коллекцию.
- Вкладка «Практики» возвращается в bottom navigation и использует существующий экран/компоненты, без отдельного дизайн-переосмысления в текущем ТЗ.
- «Квест дня» и карточки-замены ему не добавляются, чтобы не раздувать scope.
- Слово «капсула» не используется в UI; публичная терминология — «Шаг», «Карта пути», «Программа».

## Техническая платформа

- **Frontend:** Nuxt 4 (Vue 3), Tailwind CSS 4, TypeScript
- **Backend:** Nitro (Node.js), Drizzle ORM, PostgreSQL, Redis, BullMQ
- **AI:** OpenAI GPT-4 (чат), OpenAI Realtime API (голос), OpenAI TTS/Whisper (голос)
- **Mobile:** Capacitor (нативные iOS 15+ и Android 8+ приложения поверх web-сборки)
- **Инфраструктура:** VPS, Nginx, Traefik, Docker
- **Медиа:** CDN (media.mentala.app) для аудио и изображений
