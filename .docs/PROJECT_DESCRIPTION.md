# Mentala — Описание проекта

Мультиплатформенное приложение для психологической самопомощи на основе AI. Текстовый и голосовой чат с AI-терапевтом, трекеры привычек, дыхательные практики, медитации, персонализированные уведомления.

## Реализовано
- Онбординг и регистрация (email + OAuth)
- Чат с AI (текст + голос, RU/EN)
- Система подписок (Basic/PRO/Premium) + YooKassa
- Персонализированные уведомления (AI + шаблоны)
- Медитации и дыхательные практики
- Быстрая помощь (SOS)
- Дневник благодарности

## Платформы
- Web (Nuxt 4)
- iOS (Capacitor, iOS 15+)
- Android (Capacitor, Android 8+)
