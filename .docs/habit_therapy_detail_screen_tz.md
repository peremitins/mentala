# ТЗ: Экран детали привычки/темы + вход в чат

Документ описывает UX/UI и логику экрана детали для вкладок «Привычки» и «Терапия», а также вход в чат с контекстом выбранной сущности.

## 1. Цели

- Убрать зависимость чата от пользовательского выбора «активного промпта».
- Ввести единый UX: список → экран детали → доступ к настройкам уведомлений и вход в чат.
- Снизить когнитивную нагрузку: пользователь выбирает «о чём говорить», система решает «как говорить».

## 2. Навигация

- Привычки/Терапия → список → клик по элементу → **новый экран детали**.
- На экране детали:
  - Primary CTA: «Поговорить об этом».
  - Карточка «Уведомления» со сводкой + кнопка «Изменить».

## 3. Экран детали — структура (сверху вниз)

### 3.1 Header

- Остаётся как сейчас (название, эмодзи, back).

### 3.2 Основной CTA

- Кнопка: «Поговорить об этом».
- Визуально главная, с мягкой анимацией появления и нажатия.
- Действие: открывает общий чат с `entryContext` (см. раздел 6).

### 3.3 Карточка «Уведомления»

- Блок с краткой сводкой:
  - Частота: `timesPerDay`.
  - Окно времени: `timeRangeStart`–`timeRangeEnd`.
  - Дни: `activeDays`.
  - Статус: включены/выключены.
- Кнопка «Изменить» → переход на существующий экран настроек уведомлений.

### 3.4 Визуальный стиль

- Glassmorphism: мягкие тени, `backdrop-blur`, полупрозрачные панели.
- Градиенты/световые акценты для CTA и карточек.
- Анимации: лёгкое появление блоков сверху вниз, hover‑подсветки.

## 4. Изменения в списке привычек/тем

- На карточке элемента добавить кнопку «ИИ чат».
- Логика:
  - Клик по карточке → экран детали.
  - «ИИ чат» → общий чат с `entryContext` выбранного элемента.
- Кнопка не отображается на карточке «Создать свою привычку/тему».

## 5. Изменения вкладки «Промпты»

- В UI скрыть вкладку «Промпты».
- Код и сущности промптов **не удалять**.

## 6. Контекст входа в чат (entryContext)

### 6.1 Формат

- Для привычки:
  - `type: "habit"`
  - `habit_id: <id>`
- Для темы терапии:
  - `type: "therapy_topic"`
  - `topic_id: <id>`

### 6.2 Поведение

- Контекст передаётся при входе в чат с экрана детали или из списка по кнопке «ИИ чат».
- Контекст **не становится глобально активным навсегда** — это входной параметр диалога.

## 7. Данные для сводки уведомлений

- Источник: `NotificationPreferencesDto`.
- Маппинг:
  - `timesPerDay` → «Частота: X раз(а) в день».
  - `timeRangeStart`/`timeRangeEnd` → «Окно: HH:mm – HH:mm».
  - `activeDays` → «Дни: Пн, Вт, ...».
  - `enabled` → «Включены»/«Выключены».
- Если настроек нет:
  - Текст «Уведомления не настроены».
  - CTA «Настроить».

## 8. Состояния

- Loading: скелетоны карточек/сводок.
- Empty: нет настроек уведомлений.
- Error: отображение состояния с возможностью ретрая.

## 9. Критерии готовности

1. Клик по привычке/теме открывает экран детали, а не настройки уведомлений.
2. На деталях есть:
   - CTA «Поговорить…»
   - Карточка «Уведомления» со сводкой и переходом в настройки
3. В чате при входе с деталей ассистент стартует с нужным `entryContext`.
4. Вкладка «Промпты» скрыта в UI, логика в коде сохранена.

## 10. Ограничения и совместимость

- Кроссплатформенность: Web (Chrome/Firefox/Safari/Edge), iOS 13+, Android 8+.
- Все async‑операции через `async/await`.
- Никаких платформо‑специфичных API без проверки доступности.
