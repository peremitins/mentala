# Техническое задание: редизайн раздела «Практики» и добавление «Мой набор»

## 1. Цель изменений

Нужно упростить раздел «Практики» и добавить персональный раздел «Мой набор», в котором пользователь сможет быстро вернуться к техникам, фразам, поддерживающим действиям и другим материалам, которые он выбрал во время прохождения Roadmap-программ.

Главная цель - сделать так, чтобы Roadmap не был одноразовым прохождением шагов. Пользователь должен сохранять полезные для себя инструменты и потом возвращаться к ним в разделе «Практики».

## 2. Основные решения

### 2.1. Не добавлять «Мой набор» на главный экран

На главном экране отдельный блок «Мой набор» не нужен.

Причины:

- главный экран уже содержит много информации;
- основной фокус главного экрана должен оставаться на текущем шаге программы и ключевых действиях;
- «Мой набор» логичнее разместить внутри раздела «Практики», где пользователь уже ожидает найти упражнения и инструменты.

### 2.2. Добавить раздел «Мой набор» в «Практики»

В разделе «Практики» первым или одним из первых блоков нужно добавить карточку/раздел:

```txt
Мой набор
```

Краткое описание:

```txt
Практики, фразы и действия, которые ты выбрал для себя.
```

Альтернативный вариант описания:

```txt
Всё, к чему ты решил возвращаться после прохождения программ.
```

Рекомендуемый вариант:

```txt
Практики, фразы и действия, которые ты выбрал для себя.
```

## 3. Что хранится в «Моём наборе»

В «Мой набор» должны попадать не только практики, но и другие полезные элементы из Roadmap.

### 3.1. Типы элементов

В наборе могут быть:

- дыхательные практики;
- медитации;
- заземление;
- снятие напряжения;
- выгрузка мыслей;
- переход к ИИ-ассистенту;
- личные фразы пользователя;
- фразы на трудный день;
- фразы на случай перегруза;
- просьбы о поддержке;
- люди или источники поддержки;
- маленькие действия, выбранные пользователем;
- другие элементы, которые пользователь сохранил во время Roadmap.

## 4. Структура «Моего набора»

Раздел нужно сделать не просто списком, а сгруппировать элементы по смыслу.

Рекомендуемая структура:

```txt
Мой набор

Практики
- Заземление 5-4-3-2-1
- Снятие напряжения
- Дыхание 4-6
- Медитация внимания к телу

Мои фразы
- Сегодня можно сделать меньше
- Я вернусь к этому позже
- Сейчас важнее не перегрузить себя

Поддержка
- Попросить помощи
- Написать близкому человеку
- Обратиться к специалисту

ИИ-ассистент
- Разобрать ситуацию
- Поговорить, когда тяжело
```

На первой версии можно сделать проще:

```txt
Мой набор

Практики
Мои фразы
Поддержка
```

## 5. Поведение элементов

### 5.1. Практики

Если элемент является практикой, по нажатию пользователь должен попадать сразу в запуск этой практики.

Примеры:

- «Заземление 5-4-3-2-1» открывает экран заземления;
- «Снятие напряжения» открывает соответствующую телесную практику;
- «Дыхание 4-6» открывает дыхательную практику;
- «Медитация внимания к телу» открывает медитацию.

Важно: пользователь не должен попадать обратно в старый шаг Roadmap. Элемент должен открываться как самостоятельная практика.

### 5.2. ИИ-ассистент

Если элемент связан с ИИ-ассистентом, по нажатию пользователь должен переходить в соответствующий режим ассистента.

Пример:

```txt
Поговорить с помощником
```

Возможное поведение:

- открывается экран чата;
- в чат можно передать контекст режима, например `support`, `hard_day`, `self_kindness`;
- сам текст старой переписки редактировать нельзя.

### 5.3. Личные фразы

Личные фразы пользователь должен иметь возможность:

- просматривать;
- редактировать;
- удалять;
- добавлять вручную.

Это важно, потому что во время прохождения Roadmap пользователь мог написать фразу быстро или не очень удачно. Позже он должен иметь возможность привести её в нормальный вид.

### 5.4. Поддержка и люди

Если пользователь сохраняет людей или способы поддержки, такие элементы можно редактировать и удалять.

Примеры элементов:

```txt
Написать другу
Позвонить близкому человеку
Обратиться к специалисту
```

В первой версии не нужно делать сложную интеграцию с контактами. Достаточно текстового элемента.

## 6. Редактирование и удаление

Не все элементы должны редактироваться одинаково.

### 6.1. Можно редактировать

Можно редактировать:

- личные фразы;
- фразы на трудный день;
- фразы на случай перегруза;
- пользовательские заметки;
- текстовые элементы поддержки;
- маленькие действия пользователя.

### 6.2. Нельзя редактировать

Нельзя редактировать:

- системные практики;
- названия стандартных дыхательных практик;
- названия стандартных медитаций;
- системные маршруты в ИИ-ассистент;
- историю чата.

Для таких элементов можно дать действия:

- открыть;
- убрать из набора;
- добавить в избранное, если будет отдельная логика избранного.

### 6.3. Удаление

Любой элемент можно убрать из «Моего набора».

После удаления желательно показать toast:

```txt
Убрано из набора
```

Если элемент текстовый, можно добавить восстановление через undo:

```txt
Убрано из набора · Вернуть
```

## 7. Добавление вручную

В разделе «Мой набор» нужна возможность добавить пользовательский элемент вручную.

Минимальная версия:

```txt
Добавить фразу
Добавить действие
Добавить источник поддержки
```

Для первой версии достаточно добавить только:

```txt
Добавить фразу
```

Остальное можно реализовать позже.

## 8. Источник элемента

У каждого элемента желательно хранить источник.

Пример:

```txt
Добавлено из сада «Доброта к себе»
```

Или компактно:

```txt
Из сада «Доброта к себе»
```

Это не обязательно показывать на карточке в первом экране, но полезно хранить в базе.

## 9. Поведение при повторном добавлении

Если пользователь в разных садах выбирает одну и ту же системную практику, не нужно создавать дубликаты.

Пример:

Пользователь добавил:

- «Заземление 5-4-3-2-1» из сада тревоги;
- «Заземление 5-4-3-2-1» из сада доброты к себе.

В «Моём наборе» должна быть одна карточка:

```txt
Заземление 5-4-3-2-1
```

При этом внутри данных можно хранить несколько источников.

## 10. Убрать раздел «Быстрая помощь»

Текущий раздел «Быстрая помощь» нужно убрать как отдельный раздел.

Причины:

- он выглядит как недоразвитая отдельная фича;
- часть элементов дублирует другие разделы;
- пользователю проще видеть все практики в одном общем разделе;
- «Мой набор» лучше решает задачу быстрого доступа к тому, что человеку подходит.

## 11. Что сделать с практиками из «Быстрой помощи»

Из раздела «Быстрая помощь» нужно перенести уникальные техники в общий список практик.

### 11.1. Перенести

Перенести в общий список практик:

```txt
Заземление 5-4-3-2-1
Снять напряжение в теле
Выгрузка мыслей
```

Эти техники полезные и не должны пропадать.

### 11.2. Удалить как отдельные быстрые пункты

Удалить из отдельного раздела «Быстрая помощь»:

```txt
Стабилизировать дыхание
Хочу выговориться
```

Причины:

- «Стабилизировать дыхание» дублирует раздел дыхательных практик;
- «Хочу выговориться» дублирует переход к ИИ-ассистенту и чат;
- эти пункты не должны жить в отдельном разделе.

## 12. Новая структура раздела «Практики»

Рекомендуемая структура после изменений:

```txt
Практики

ИИ-ассистент
Мой набор
Дыхательные практики
Медитации
Заземление
Снятие напряжения
Выгрузка мыслей
Дневник благодарности
```

Возможная структура карточек:

```txt
ИИ-ассистент
Поддержка и разбор ситуации в чате

Мой набор
То, что ты выбрал для себя в программах

Дыхательные практики
Готовые упражнения и индивидуальные настройки

Медитации
Практики для отдыха, внимания и концентрации

Заземление
Быстро вернуться в настоящий момент через ощущения

Снятие напряжения
Короткая практика для тела и расслабления

Выгрузка мыслей
Записать мысли и немного освободить голову

Дневник благодарности
Короткие записи о хороших моментах дня
```

## 13. Что добавить в Roadmap

В шагах Roadmap, где пользователь выбирает техники или пишет важные фразы, нужно добавить сохранение в «Мой набор».

Примеры источников:

- шаг «Мой набор самоподдержки»;
- шаг «Фраза на случай перегруза»;
- шаг «Фраза на трудный день»;
- шаг «Собрать просьбу»;
- шаги, где пользователь выбирает дыхание, заземление, медитацию или ИИ-ассистента как подходящий инструмент.

После сохранения показывать текст:

```txt
Добавлено в «Мой набор»
```

Если элемент уже был добавлен:

```txt
Уже есть в «Моём наборе»
```

## 14. Минимальная версия реализации

Для первой версии нужно сделать:

1. Убрать отдельный раздел «Быстрая помощь».
2. Перенести «Заземление», «Снятие напряжения», «Выгрузку мыслей» в общий список практик.
3. Добавить раздел «Мой набор» в «Практики».
4. Сохранять выбранные пользователем элементы из Roadmap в «Мой набор».
5. Поддержать типы элементов:
   - системная практика;
   - личная фраза;
   - действие;
   - поддержка;
   - ИИ-ассистент.
6. Для текстовых элементов добавить редактирование и удаление.
7. Для системных практик добавить открытие и удаление из набора.
8. Не добавлять блок «Мой набор» на главный экран.

## 16. Пример поведения карточек

### 16.1. Практика

```txt
Заземление 5-4-3-2-1
Вернуться в настоящий момент через наблюдение и ощущения
[Открыть]
```

Действия:

- открыть практику;
- убрать из набора.

### 16.2. Личная фраза

```txt
Сегодня можно сделать меньше
Фраза на трудный день
[Редактировать]
```

Действия:

- редактировать;
- удалить;
- скопировать, если нужно.

### 16.3. Поддержка

```txt
Написать близкому человеку
Источник поддержки
[Открыть]
```

Действия:

- редактировать;
- удалить.

### 16.4. ИИ-ассистент

```txt
Разобрать ситуацию с помощником
Поддержка в чате
[Открыть чат]
```

Действия:

- открыть чат;
- убрать из набора.

## 17. Требования к UX

- «Мой набор» должен быть доступен из раздела «Практики».
- Пользователь должен быстро понимать, что это его личная подборка.
- Внутри не должно быть ощущения медицинского кабинета или сложного справочника.
- Текст должен быть простым и коротким.
- Не нужно использовать технические формулировки вроде «инструменты Roadmap», «daily loop», «маршрут».
- Удаление должно быть безопасным, желательно с возможностью отмены.
- Если набор пустой, показать понятное пустое состояние.

## 18. Пустое состояние

Если в «Моём наборе» ещё ничего нет:

```txt
Здесь появятся практики, фразы и действия, которые ты выберешь для себя в программах.
```

Кнопка:

```txt
Перейти к программам
```

## 19. Итоговое решение

Реализуем «Мой набор» как общий персональный раздел внутри «Практик».

Раздел «Быстрая помощь» удаляем как отдельный раздел.

Уникальные практики из него переносим в общий список практик:

- заземление;
- снятие напряжения;
- выгрузка мыслей.

Дублирующие элементы удаляем:

- стабилизировать дыхание;
- хочу выговориться.

«Мой набор» становится местом, где пользователь хранит то, что выбрал для себя во время прохождения программ: практики, фразы, действия и поддержку.
