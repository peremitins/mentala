# ТЗ: Лендинг Mentala

## 1. Общие положения

- **URL:** mentala.app
- **Приложение:** my.mentala.app
- **Структура в проекте:** `frontend/landing/`

```
frontend/
├── app/              # Nuxt (my.mentala.app)
├── landing/          # Чистый HTML (mentala.app)
│   ├── index.html
│   ├── css/
│   │   └── style.css
│   ├── js/
│   │   └── main.js
│   └── images/
```

- **Стек:** HTML + CSS + vanilla JS (без фреймворков)
- **Формат:** одностраничник (one-page)
- **Бэкенд:** только обработка одной формы (отправка заявки)

---

## 2. Требования

| Требование | Описание |
|------------|----------|
| SEO | Meta-теги, Open Graph, JSON-LD, sitemap.xml, robots.txt |
| Адаптивность | Mobile-first, корректный вид на телефонах и десктопе |
| Анимации | CSS (transition, keyframes), при необходимости — минимальный JS |
| Форма | Одна форма (заявка/контакт), отправка на API |
| Ссылки | CTA «Попробовать» / «Начать» → https://my.mentala.app/auth |

---

## 3. Уточняющие вопросы

### Контент
1. **Блоки/секции:** какие нужны? (Hero, преимущества, функции, отзывы, тарифы, форма заявки, FAQ, footer?)
2. **Языки:** только RU или RU + EN?
3. **Тексты:** есть готовые или нужен шаблон/черновик?

### Форма
4. **Назначение формы:** заявка на обратный звонок, подписка на рассылку, другая?
5. **Поля:** какие (имя, email, телефон, сообщение)?
6. **Куда отправлять:** endpoint на my.mentala.app (нужно ли создать `POST /api/landing/contact`?) или внешний сервис (Formspree, SendGrid и т.п.)?

### Дизайн
7. **Стиль:** опираться на приложение (тёмная тема, палитра из tailwind.css) или отдельный дизайн?
8. **Есть референс/макет?** (Figma, ссылка на пример)

### Юридическое
9. **Ссылки в footer:** политика конфиденциальности, оферта — куда ведут? На my.mentala.app/legal или отдельные страницы на лендинге?

### Деплой
10. **Хостинг:** тот же сервер (nginx) или отдельно (Vercel, Netlify)?
