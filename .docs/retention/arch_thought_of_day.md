# «Мысль дня» — архитектура и ТЗ v2

Дата: 2026-05-31. Статус: ТЗ для реализации после P1-релиза.

## Текущее состояние (P1, до релиза)

«Мысль дня» — одна текстовая карточка на главной. Создаётся при первом вызове
`/api/today` за день, не меняется при перезагрузке. Пользователь может сохранить
её в коллекцию (1 капля).

Контент сейчас: статичный fallback-каталог в коде.
- `calm_anxiety_30`: 5 текстов, ротация по hash(userId + entryDate).
- `self_kindness_21`: 21 текст, по номеру текущего шага.
- Итого: при 5 текстах повтор наступает на 6-й день. Неприемлемо для retention.

**Решение для P1-релиза:** расширить встроенный каталог до 60 текстов
(универсальный кластер) с ротацией без повторов за 60 дней (описано ниже в разделе
«Быстрое улучшение»). Так продукт уходит в релиз с приемлемым UX, не блокируя
разработку полноценной v2.

## Форматы текстов: что работает

### CBT-переформулировка (рекомендуется как основной формат)
Короткое наблюдение + когнитивный сдвиг. Доказательная база, применимость,
конкретность. Примеры:
- «Тревога часто убеждает, что опасность огромна, а мы слишком малы. На деле
  всё наоборот — тревога появляется там, где нам что-то важно.»
- «Мысль — это не факт. Её можно проверить, как гипотезу.»

### Self-compassion инсайты (для «Доброты к себе»)
Не аффирмации, а нормализация и мягкое переключение.
- «Самокритика кажется полезной, но обычно только сужает внимание. Поддержка
  работает надёжнее.»

### Мини-вызовы (низкий барьер, высокая применимость)
Одно действие на день, не задание:
- «Сегодня заметьте одну мысль, которую вы принимаете за факт.»

### Что не работает
- **Классические аффирмации** («Я сильный, я смогу») — у людей с тревогой
  вызывают когнитивный диссонанс, могут ухудшать состояние (исследования Joanne
  Wood, 2009).
- **Цитаты великих** — высокий риск «токсичного позитива» и обесценивания.
  Можно использовать как дополнительный слой, не как основной формат.
- **Директивный совет** («Сделайте X, чтобы Y») — воспринимается как задание,
  создаёт давление.

## Рекомендуемая архитектура v2

### Кластерная структура каталога

| Кластер | Когда используется | Объём (минимум) |
|---|---|---|
| `universal` | Всегда, если нет точного совпадения | 90 текстов |
| `calm_anxiety` | Программа «Спокойствие» активна | 60 текстов |
| `self_compassion` | Программа «Доброта к себе» активна | 60 текстов |
| `low_mood` | Mood check-in ≤ 2 («очень плохо» / «грустно») | 30 текстов |
| **Итого** | | **240 текстов** |

### Алгоритм выбора (приоритет сверху вниз)

1. Если mood check-in ≤ 2 сегодня → выбрать из `low_mood`
2. Если пользователь активен в программе → выбрать из кластера программы
3. Иначе → из `universal`
4. **Анти-повтор:** никогда не повторять текст из последних 60 дней для этого пользователя
5. Из отфильтрованного набора — случайный выбор (или взвешенный по реакциям в будущем)

### Схема хранения

```sql
-- Каталог (управляется редактором)
thought_of_day_catalog (
  id           bigserial PRIMARY KEY,
  text         text NOT NULL,
  cluster      varchar(32) NOT NULL,  -- 'universal' | 'calm_anxiety' | 'self_compassion' | 'low_mood'
  mood_max     smallint,              -- NULL = подходит для любого настроения; 2 = только для низкого
  tags         text[] DEFAULT '{}',
  active       boolean DEFAULT true,
  created_at   timestamptz DEFAULT now()
)

-- История показов (для анти-повтора)
user_thought_of_day_log (
  id          bigserial PRIMARY KEY,
  user_id     integer REFERENCES users(id) ON DELETE CASCADE,
  thought_id  bigint REFERENCES thought_of_day_catalog(id),
  shown_date  varchar(10) NOT NULL,  -- YYYY-MM-DD, локальная дата пользователя
  saved       boolean DEFAULT false,
  reacted     varchar(20),           -- 'resonated' | 'neutral' | NULL (future use)
  created_at  timestamptz DEFAULT now(),
  UNIQUE (user_id, shown_date)
)
```

### Кэширование

Redis ключ: `thought:day:{userId}:{YYYY-MM-DD}`, TTL до конца суток пользователя.
Это исключает повторный SELECT при каждом запросе `/api/today`.

### API (обновлённый)

```
GET  /api/thought-of-the-day         — текущая мысль дня (без изменений)
POST /api/thought-of-the-day/save    — сохранить (1 капля, идемпотентно)
DELETE /api/thought-of-the-day/save  — убрать из коллекции
GET  /api/thoughts/collection        — коллекция сохранённых
POST /api/thoughts/today/react       — реакция (future use, не блокирует v2)
```

## AI-генерация: когда оправдана

**Не в ядре, а как ускоритель производства контента.**

Схема:
1. Редактор задаёт кластер, тон и 3–5 примеров-эталонов
2. LLM (Claude) генерирует 20 вариантов
3. Редактор выбирает 5–7, правит под стиль Mentala
4. Финальные тексты попадают в каталог через CMS или напрямую в БД

Это ускоряет масштабирование с 240 до 365+ текстов, но не заменяет редакционный контроль.

Риски самостоятельной AI-генерации без контроля: токсичный позитив, потеря нюансов,
неуместный текст для пользователя в низком настроении.

## Быстрое улучшение для P1-релиза

До реализации полной v2 — расширить встроенный fallback-каталог в коде:

**Цель:** 60 текстов в `THOUGHT_TEMPLATES` (универсальный кластер) вместо 5.
Этого хватает на 60+ дней без повтора.

**Ротация без повтора:** текущий hash(userId + entryDate) % N автоматически
«разводит» разных пользователей по разным текстам. При N=60 конкретный пользователь
повторит текст не раньше чем через 60 дней — приемлемо для P1.

**Что написать:** 60 коротких CBT-инсайтов и self-compassion наблюдений по теме
тревоги, стресса и самоотношения. Тон: тёплый, без директивности. Длина: 1–2
предложения, 30–80 слов. Без клинических аббревиатур и длинных тире.
