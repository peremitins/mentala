# ТЗ: «Быстрая помощь» как единый экран вместо SOS + вход из «Практик»

Статус: актуализировано под текущий код фронтенда на 27.02.2026.

## 1. Цель

Сделать «Быструю помощь» единым экраном быстрых техник (микро-практик), который:

- доступен из хедера (текущая кнопка SOS);
- доступен из раздела «Практики» как отдельная плитка;
- переиспользует текущую реализацию SOS-страницы без дублирования логики;
- убирает лишнюю вложенность выбора внутри сценария «Тревога и паника».

## 2. Подтвержденное текущее состояние (по коду)

### 2.1 Маршруты и точки входа

- Единственный маршрут: `/sos` (`app/pages/sos.vue`).
- В `PageHeader` кнопка с иконкой `heart-pulse` ведет на `/sos` и скрыта на самой странице SOS (`route.name !== 'sos'`).
- В `app/pages/practices/index.vue` сейчас только 2 плитки: «Медитации» и «Дыхательные практики».
- В чате action-chip `open_sos` ведет на `/sos` с `query.entry` (`panic | tension | technique_picker`) в `app/pages/index.vue`.

### 2.2 Структура SOS-экрана

- Заголовок страницы: `SOS` (`app/pages/sos.vue`).
- Основной контент: `app/components/sos/SosPageContent.vue`.
- Текущие шаги в `useSos`:
  - `select`;
  - `panic-techniques`;
  - `panic-grounding`;
  - `panic-breathing`;
  - `tension-practice`;
  - `finish`.
- На первом экране (`select`) 3 карточки:
  - «Тревога и паника»;
  - «Сильное напряжение»;
  - «Хочу выговориться».
- Для «Тревога и паника» есть вложенный шаг `panic-techniques` с 2 карточками:
  - «5-4-3-2-1»;
  - «Квадратное дыхание 4-4-4-4».

### 2.3 Важные ограничения и зависимости

- Переход в чат из SOS ограничен entitlement-ключом `sos.chat_handoff` (paywall-блокировка для недоступных тарифов).
- Контекст в чат передается как `entryContext.type = 'sos'` с полями `sos_entry` и `after_practice`.
- В `default` layout фон сцены приглушается на route `/sos` во время SOS-техник.

## 3. Расхождения с целевой концепцией «Быстрой помощи»

1. Нет канонического маршрута `/quick-help` (сейчас только `/sos`).
2. Нет плитки «Быстрая помощь» в разделе «Практики».
3. Заголовок экрана не переименован (сейчас `SOS`).
4. Есть промежуточный экран `panic-techniques`, который нужно убрать.
5. Нет единого конфигурационного списка карточек верхнего уровня.

## 4. Требуемые изменения

### 4.1 Маршрутизация

- Ввести единый маршрут `/quick-help` как единственную точку входа.
- Обратную совместимость для `/sos` не сохранять (без alias и без редиректа).
- Обновить переход из `PageHeader` на `/quick-help`.
- Обновить переходы из action-chip `open_sos` на `/quick-help`.
- Обновить доступность кнопки в хедере:
  - `aria-label`: `Быстрая помощь` (вместо `SOS`).

### 4.2 Раздел «Практики»

Добавить третью плитку в `app/pages/practices/index.vue`:

- Заголовок: `Быстрая помощь`;
- Подзаголовок: `Короткие техники для тревоги и напряжения`;
- Иконка: `heart-pulse` (та же визуальная сущность, что в хедере SOS);
- Переход: `/quick-help`.

### 4.3 Экран «Быстрая помощь» (бывший SOS)

- Заголовок: `Быстрая помощь`.
- Верхний уровень должен сразу содержать 4 карточки:
  1. `5-4-3-2-1` — `Заземление через наблюдение и ощущения`.
  2. `Стабилизировать дыхание` — `Квадратное дыхание 4-4-4-4`.
  3. `Сбросить сильное напряжение` — `Расслабить тело и сделать дыхание ровнее`.
  4. `Хочу выговориться` — `Поговорить в чате`.
- Убрать промежуточный шаг `panic-techniques` из пользовательского основного потока.

### 4.4 Техническая реализация без дублирования

- Источник данных карточек хранить в одном месте (например, `app/lib/quickHelpCatalog.ts`).
- Формат элемента каталога:
  - `id`;
  - `title`;
  - `subtitle`;
  - `icon`;
  - `actionType` (`set_step | go_chat`);
  - `actionPayload` (`step` или `entry`).
- `SosPageContent` рендерит карточки из каталога, а не через дублирующие хардкоды.
- `useSos` упростить:
  - удалить `panic-techniques`;
  - скорректировать `resolveInitialStep(entry)`:
    - `panic` -> `panic-grounding` (прямой вход в `5-4-3-2-1`);
    - `tension` -> `tension-practice`;
    - `technique_picker` и отсутствие `entry` -> верхний уровень из 4 карточек.

### 4.5 Совместимость с текущей логикой

- Не менять ключи entitlement (`sos.chat_handoff`) и тип контекста чата (`type: 'sos'`) на этом этапе.
- Сохранить текущие экраны техник:
  - `panic-grounding` (5-4-3-2-1),
  - `panic-breathing` (box breathing),
  - `tension-practice` (PMR).
- Обновить проверку приглушения фонового аудио в `app/layouts/default.vue` с учетом `/quick-help`.

## 5. Тексты и нейминг

- Название «Антипаника» не использовать.
- Для карточки дыхания использовать:
  - Заголовок: `Стабилизировать дыхание`;
  - Подпись: `Квадратное дыхание 4-4-4-4`.
- Остальные тексты брать из текущих формулировок SOS, где это не конфликтует с новым верхним уровнем.

## 6. Критерии приемки

1. В «Практиках» отображается плитка «Быстрая помощь» с корректной иконкой.
2. Кнопка в хедере и плитка в «Практиках» открывают один и тот же экран.
3. Единственный путь: `/quick-help`; переходы на `/sos` в приложении отсутствуют.
4. Заголовок страницы: `Быстрая помощь`.
5. На верхнем уровне 4 карточки: `5-4-3-2-1`, `Стабилизировать дыхание`, `Сбросить сильное напряжение`, `Хочу выговориться`.
6. Вложенный экран `panic-techniques` не используется в основном пользовательском потоке.
7. Переходы в техники и в чат сохраняют текущую функциональность.
8. Нет дублирования данных карточек между разными точками входа.

## 7. Принятые решения

1. Обратная совместимость маршрута `/sos` не требуется.
2. `entry=panic` открывает сразу технику `5-4-3-2-1`.
3. Кнопка в хедере переименовывается в `Быстрая помощь` (включая `aria-label`).
