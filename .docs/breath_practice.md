

1) Список дыхательных практик для Mental (проверено, без “придуманных”)

Я убираю спорные/недостаточно надёжные для “клинической” подачи (вроде Вим Хоф/Бутейко) из базового каталога. Их можно добавить потом как “экспериментальные” с дисклеймером — но не в основной список MVP.

Каталог MVP (9 практик) + Custom

Все длительности фаз — целые секунды.
	1.	4-7-8 (Сон / успокоение)
Паттерн: вдох 4 → задержка 7 → выдох 8
Коротко: техника расслабления, часто рекомендуют для снижения напряжения и как вечерний ритуал.  ￼
	2.	Box breathing 4-4-4-4 (Фокус / стабилизация)
Паттерн: вдох 4 → задержка 4 → выдох 4 → задержка 4
Коротко: “квадратное дыхание” для концентрации и снижения стресса.  ￼
	3.	Ровное дыхание 5-5 (Баланс / восстановление)
Паттерн: вдох 5 → выдох 5
Коротко: тот же принцип, только медленнее (подходит тем, кому комфортнее “длиннее”).  ￼
	5.	Удлинённый выдох 4-6 (Снятие тревоги / успокоение)
Паттерн: вдох 4 → выдох 6
Коротко: простой анти-стресс, легко делать “на ходу”, без задержек.
	6.	Pursed-lip breathing 2-4 или 2-6 (Контроль дыхания / снижение напряжения)
Паттерн (вариант): вдох 2 → выдох 4–6 через сомкнутые губы
Коротко: медицински известная техника замедления выдоха, часто применяют при одышке и тревоге.  ￼
	7.	Диафрагмальное (брюшное) дыхание (База / успокоение)
Паттерн: вдох 4–6 → выдох 4–6 (в приложении оформить как 4-4 или 4-6)
Коротко: базовая техника “дышать животом”, часто рекомендуемая для релаксации и снижения стресса. (Есть в подборках мед-источников рядом с box/4-7-8).  ￼
	8.	Alternate nostril breathing (Баланс / ясность)
Паттерн: по сути “вдох/выдох” с подсказкой смены ноздри; в тренажёре ведём фазами и текстом.
Коротко: широко известная пранаяма, есть обзоры/статьи и публикации.  ￼
	9.	Physiological sigh / cyclic sighing (Быстрое снижение стресса)
Паттерн: двойной вдох → длинный выдох (в UI: “Вдох 1”, “Добор”, “Длинный выдох”)
Коротко: в исследованиях и материалах Stanford/публикациях описывают улучшение настроения/снижение тревоги при регулярной практике.  ￼
	10.	Custom (пользовательская практика)
Паттерны 2/3/4 фазы, секунды 1–30, целые числа, сохранить в профиле.

2) Костяк ТЗ (MVP) — раздел «Дыхательные практики»

Ниже прям скелет, который можно оформить в .md как ТЗ.

2.1. Цель

Добавить в Mental раздел “Дыхательные практики” — интерактивный тренажёр с:
	•	каталогом популярных практик (список выше),
	•	экраном тренажёра с градиентной сферой (вдох/задержка/выдох),
	•	настройкой длительности по времени (минуты + кастом),
	•	возможностью создать/сохранить пользовательские практики (2–4 фазы),
	•	звуком (архитектура заложена, детали выбора — следующим шагом).

2.2. Экраны

A) Экран каталога
	•	Секции:
	•	“Популярные”
	•	“Сон”
	•	“Снятие тревоги”
	•	“Фокус”
	•	“Мои практики” (custom)
	•	Карточка практики:
	•	Название (например, “4-7-8”)
	•	Короткая цель (сон/успокоение/фокус)
	•	Краткое описание (1–2 строки “чем помогает”)
	•	Кнопка “Начать”
	•	Кнопка “Создать свою практику”

B) Экран тренажёра
	•	Центр: сфера (aurora/glass градиент в стиле Mentala)
	•	Текст фазы: “Вдох / Задержка / Выдох / Пауза” (если 4 фазы)
	•	Обратный отсчёт секунды в фазе
	•	Верх: название практики + паттерн (например “4-7-8”)
	•	Низ:
	•	Start/Pause
	•	Stop
	•	Настройки (времени, звука, вибро)
	•	Перед стартом: “Подготовьтесь 3…2…1”

C) Экран создания Custom практики
UI должен быть максимально “friendly”:
	•	Переключатель “Количество фаз”: 2 / 3 / 4
	•	2 фазы: Вдох / Выдох
	•	3 фазы: Вдох / Задержка / Выдох
	•	4 фазы: Вдох / Задержка / Выдох / Пауза
	•	Для каждой фазы:
	•	название (фиксированное, чтобы не путать)
	•	секундный инпут 1–30 (stepper + ручной ввод)
	•	Превью: мини-таймлайн/чипы “Вдох 4 • Пауза 4 • …”
	•	Поле имени практики
	•	“Сохранить” (в профиль)

2.3. Длительность сессии (по времени)
	•	Выбор: единая ячейка с текущими минутами (1–60), по тапу открывается список минут (TimePicker в режиме минут).
	•	Во время сессии показывать:
	•	оставшееся время
	•	прогресс (полоса/кольцо)

Поведение окончания:
	•	На 0:00 — мягкое завершение (стоп + финальный сигнал), экран “Сеанс завершён”.

2.4. Движок тайминга фаз
	•	Цикл повторяется до окончания общего времени.
	•	Смена фазы строго по таймеру, секунды целые.
	•	Поддержка 2/3/4 фаз.
	•	Максимальная длительность фазы для пользовательских практик: 30 секунд.

2.5. Звук (архитектурно, без подбора)

Настройки:
	•	Sound: on/off
	•	Громкость 0–100
	•	Тип сопровождения (позже утвердим):
	•	Cue-only (короткий сигнал на смену фазы)
	•	(опционально позже) Continuous guide (тон ведёт весь вдох/выдох)

Правило в MVP:
	•	Воспроизводить сигнал на смене фазы: он играет полностью, но при старте следующей фазы прерывается.
	•	Это снимает проблему “растягивания” при 10/20/60 сек и не режет короткие файлы.
	•	Файлы сигналов (public): `/breath/sounds/inhale.m4a`, `/breath/sounds/exhale.m4a`, `/breath/sounds/wait.m4a` (задержка), `/breath/sounds/pause.m4a` (пауза).

2.6. Хранение данных
	•	Системные практики — статический каталог в коде (как habits catalog).
	•	Пользовательские практики — в storage/БД профиля:
	•	id
	•	name
	•	phases: [{ type, seconds }] (2–4 элемента)
	•	createdAt, updatedAt
	•	Сохранить “последнюю выбранную длительность сессии”.

2.7. Не нужно на этом этапе
	•	“Библиотека целей” как отдельная сущность/страница — не делаем (как ты сказал).
	•	Рекомендательный движок по целям — не делаем.

2.8. Edge cases
	•	Пользователь поставил слишком тяжёлый паттерн (например задержка 60) — показывать предупреждение “Если дискомфорт — уменьшите задержку”.
	•	При уходе в фон: практика продолжает идти, без авто‑паузы.
	•	Отключение звука — тренажёр полностью работоспособен визуально.
