# Опросник `self_compassion_scs_sf_v1`: Оценка внутреннего критика (SCS-SF)

## 1. Назначение

Валидированная замена внутреннему `self_kindness_v1` для сада `self_kindness_21` / «Внутренний критик».

- пользовательское название: **«Оценка внутреннего критика»**;
- `shortTitle`: «Внутренний критик»;
- стартовая точка и финальный замер для сада;
- динамика без диагноза и клинических выводов.

Статус: **active, основной тест сада**. Самодельный `self_kindness_v1` удалён; сад `self_kindness_21` привязан к SCS-SF в baseline- и final-замерах (`retention-program.service.ts`).

## 2. Основа и лицензия

**Self-Compassion Scale – Short Form (SCS-SF)**, Raes F., Pommier E., Neff K.D., Van Gucht D. (2011). Краткая (12 пунктов) форма шкалы самосострадания Кристин Нефф.

Лицензия: Нефф даёт разрешение использовать шкалу *«for any purpose whatsoever, including research, clinical work, teaching, etc.»*; достаточно указать авторство (Neff, 2003). Никаких заявок и платы — как и у GAD-7.

В UI не выводим «SCS-SF» как заголовок: только в служебных полях `sourceName: 'SCS-SF'`, `licenseNote`. Пользователь видит «Оценка внутреннего критика».

## 3. Структура

- 12 пунктов, 6 субшкал (по 2 пункта): Self-Kindness, Self-Judgment, Common Humanity, Isolation, Mindfulness, Over-Identification;
- негативные субшкалы (Self-Judgment, Isolation, Over-Identification) — `reverseScored: true` (6 пунктов);
- шкала ответов 1..5;
- направление: `higher_is_better`;
- подсчёт: сумма с учётом reverse, диапазон 12–60.

## 4. Подсчёт

```text
Для прямых пунктов: балл = значение ответа (1..5).
Для reverse-пунктов: балл = 6 − значение ответа (1↔5, 2↔4, 3=3).
Итог = сумма по 12 пунктам. Минимум 12, максимум 60.
Чем выше — тем доступнее самоподдержка.
```

Reverse-формула в движке (`assessment-scoring.service.ts`): `minOptionValue + maxOptionValue − value = 1 + 5 − value`.

**Важно про экстремумы.** Из-за reverse-пунктов одинаковый ответ на все 12 пунктов НЕ даёт максимум — это нормальная психометрика (защита от «прямой линии» / acquiescence bias). Чтобы получить 60, нужно отвечать «почти всегда» на 6 прямых пунктов и «почти никогда» на 6 обратных. Минимум 12 — наоборот.

## 5. Диапазоны результата

Границы — по клинической интерпретации Нефф (средний балл 1.0–2.5 / 2.5–3.5 / 3.5–5.0). В сумме по 12 пунктам это:

| Band ID    | Баллы | Средний | Название в UI                       |
| ---------- | ----: | ------- | ----------------------------------- |
| `low`      | 12–29 | < 2.5   | Сейчас больше строгости к себе       |
| `moderate` | 30–41 | 2.5–3.5 | Иногда получается быть к себе мягче  |
| `high`     | 42–60 | ≥ 3.5   | Ты уже умеешь быть к себе теплее     |

`safetyLevel` всех диапазонов — `none` (в SCS-SF нет пунктов о самоповреждении).

## 6. Сравнение со стартовой точкой

`higher_is_better`: `delta = final − baseline`.

- `delta > 0` — самоподдержка стала доступнее (improved);
- `delta ≈ 0` (`|delta| < 2`) — примерно тот же уровень (stable);
- `delta < 0` — стала менее доступной (worse).

Тексты сравнения — в `sharedSelfCompassionComparisonCopy` (`assessment-catalog.ts`). Направление выводов проверено.
