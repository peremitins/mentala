Техническое задание: Карточка темы (Терапия)

1. Назначение карточки

Карточка представляет тему поддержки (например, «Тревога и паника») и служит:
• точкой входа в тему целиком,
• набором быстрых действий для получения поддержки.

⸻

2. Общая структура карточки

Карточка визуально делится на две зоны: 1. Основная зона темы (верхняя часть) 2. Зона быстрых действий (нижняя часть)

Вся карточка целиком должна быть визуально и поведенчески интерактивной.

⸻

3. Основная зона темы (верх)

Содержит:
• иконку темы;
• название темы;
• краткое описание (1–2 строки, с обрезкой);
• справа — иконка стрелки вправо.

Иконка стрелки:
• тип: chevron-right (›);
• размер: небольшой;
• цвет: нейтральный, с пониженной контрастностью (opacity ~40–60%);
• не является отдельной кнопкой, служит визуальным индикатором кликабельности.

Поведение:
• тап по этой зоне открывает страницу темы (обзор темы, настройки, уведомления, практики и т.д.);
• при нажатии — подсветка / pressed-state по всей области основной зоны.

⸻

4. Зона быстрых действий (низ карточки)

Расположение:
• под основной зоной темы;
• визуально отделена (отступ, линия, полупрозрачный фон или другой мягкий разделитель).

Содержит до 3 кнопок в один ряд: 1. Поговорить — переход в чат с заранее установленным контекстом выбранной темы. 2. Медитация — открывается конкретная медитация (первый трек выбранной группы). 3. Дыхание — открывается конкретная дыхательная практика (первая в выбранной группе).

Требования к кнопкам:
• компактный размер;
• одинаковая визуальная иерархия (ни одна не primary);
• текст + иконка (опционально);
• кнопки не перекрывают кликабельность основной зоны темы.
• правила скрытия приоритетнее наличия полного набора кнопок (может остаться 1 кнопка).
• для кастомных тем терапии и кастомных привычек кнопки «Медитация» и «Дыхание» скрыты.
• для некоторых системных тем/привычек кнопки «Медитация» и «Дыхание» скрыты (см. раздел 10).

⸻

5. Интерактивность и UX
   • Вся карточка кликабельна, но:
   • верхняя зона — вход в тему;
   • нижние кнопки — быстрые действия.
   • тап по фону нижней зоны (вне кнопок) — переход внутрь темы.
   • При нажатии на кнопки:
   • карточка не открывается,
   • выполняется соответствующее действие.
   • При нажатии на верхнюю часть:
   • кнопки не активируются,
   • происходит переход в тему.

⸻

6. Состояния карточки
   • Default — стандартный вид.
   • Pressed — мягкая подсветка/затемнение всей карточки или активной зоны.
   • Disabled (опционально) — если тема временно недоступна.

⸻

7. Ограничения и принципы
   • Карточка не должна выглядеть как “меню кнопок”.
   • Стрелка не должна быть доминирующим элементом.
   • Основной акцент — на теме, а не на функциях.
   • Интерфейс ориентирован на пользователей с повышенной тревожностью (без резких акцентов).

⸻

8. Критерии приёмки
   • Пользователь визуально понимает, что карточка кликабельна целиком.
   • Понятно различие между:
   • входом в тему,
   • быстрыми действиями.
   • Все доступные кнопки (1–3) помещаются в один ряд.
   • Карточка корректно масштабируется под разные темы.

⸻

9. Дыхательные практики: переключение внутри группы

Требование:
• Если пользователь запускает дыхательную практику из одной из групп, внутри плеера доступны кнопки «назад» и «вперёд» для перелистывания практик внутри выбранной группы.

Поведение:
• Контекст группы передаётся на экран плеера (например, параметром маршрута/запроса).
• «Назад/вперёд» переключают только практики из выбранной группы, сохраняя порядок группы.
• При переключении внутри группы обновляется выбранная практика без выхода из плеера.
• При переходе из «Мои практики» (если в группе больше одной практики) кнопки «назад/вперёд» также активны и листают только «Мои практики».
• При переходе с страниц «Терапия» и «Привычки» доступны только 3 группы: «Снятие тревоги», «Сон», «Фокус». Группа «Популярные» в этих переходах не используется.

Пример:
• Пользователь открывает технику «4–6» из группы «Снятие тревоги».
• В плеере доступны две кнопки: «назад» и «вперёд».
• Нажатия перелистывают только практики из «Снятия тревоги».

⸻

10. Редиректы из карточки темы (Терапия/Привычки)

Общее правило:
• При нажатии на «Медитация» и «Дыхание» открывается конкретная практика/трек — первый в списке выбранной группы.
• Порядок списка — по умолчанию, без дополнительной сортировки (как отдаёт текущий каталог/данные).
• Для кастомных тем терапии и кастомных привычек кнопки «Медитация» и «Дыхание» скрыты.
• Для некоторых системных тем терапии и привычек кнопки «Медитация» и «Дыхание» скрыты полностью — остаётся только «Поговорить» и вход по карточке.

Список системных тем терапии, где кнопки скрыты (ключи):
• selfesteem — Самооценка и самокритика
• relations — Отношения и границы
• loneliness — Одиночество

Список системных привычек, где кнопки скрыты (ключи):

• steps — Больше двигаться
• nutrition — Регулярное питание

• alcohol — Меньше алкоголя
• sugar — Меньше сахара
• junk_food — Меньше вредной пищи
• procrastination — Меньше прокрастинации

Единственная привычка, где кнопки показываются: «Медитация и дыхание» (meditation).
