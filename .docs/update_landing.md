## Позиционирование (v2)

**Конкурентный контекст:**

| Конкурент | Позиционирование | Что есть | Чего нет |
|---|---|---|---|
| Dzeny | «ИИ-психолог 24/7» | Нативное приложение, чат, план | Реальной программы со шагами, практик, геймификации |
| Aura | «7 методов КПТ» | Веб + Telegram-бот, глубокий чат | Нативного приложения, программы, практик |

**Незанятая ниша:** структурированная программа + ИИ-поддержка + встроенные практики в нативном приложении. Это Ментала.

**Главная идея v2:**
Ментала - это не «ещё один чатбот с ИИ» (таких уже десятки). Ментала - ИИ-психолог, у которого есть для тебя программа. Ты идёшь по пути, видишь прогресс, а ИИ рядом на каждом шаге.

**Позиционирование hero (Вариант B):**

## Принятые решения (актуализация)

1. Отзывов нет - блок не делаем.
2. «Без привязки карты» не пишем (звучит странно).
3. Воронка Вариант B сохранена: кнопка «Оценить состояние» → авторизация → тест → онбординг → главная. Всё уже работает на app-side.
4. Блок «Узнаёте себя?» (4 карточки тревоги) из v1 **убран** — его заменил новый блок «Направления» с 9 темами.
5. iOS ещё не готов — не упоминаем в CTA кнопках. Только Android + браузер.
6. Все 9 направлений показываем сразу, **без меток «скоро»** — как готовый продукт (по решению владельца: сады будут добавляться, пока юзер проходит первые два).
7. Блок «Не просто чат»: **без таблицы сравнения с конкурентами**. Только наши преимущества (3 пилона). Конкурентов не называем и не критикуем.
8. Hero secondary CTA «Оценить своё состояние» ведёт **сразу в воронку** (авторизация → тест), без промежуточного скролла — меньше кликов.
9. Topics — до Assessment. Итоговый порядок: hero → topics → differentiator → assessment → how-it-works → features → why → pricing → privacy → faq → download.
