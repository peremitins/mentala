# ТЗ: Реструктуризация страницы настроек (IA + UX)

## 0. Контекст

Сейчас экран настроек перегружен: на одном экране одновременно поля ввода, переключатели, информационные блоки и CTA. Это создаёт когнитивную нагрузку и делает страницу визуально «шумной». Цель — привести настройки к привычному для мобильных приложений паттерну **Grouped List + Drill-down**, как в iOS Settings / Telegram / Calm.

## 1. Цели

1. Убрать хаос: главный экран — только список разделов, без инпутов и длинных блоков.
2. Сократить визуальный шум: редко меняемые параметры увести на вложенные экраны.
3. Усилить смысловую иерархию: профиль → продуктовые настройки → приватность → системные → служебное.
4. Сохранить glassmorphism и текущую визуальную ДНК приложения.

## 2. Вне рамок

- Изменение бизнес-логики подписки и платежей.
- Добавление новых пользовательских данных/параметров.
- Переработка систем уведомлений (локальные настройки привычек/терапии).
- Введение светлой темы (приложение остаётся в dark-only).

## 3. Принципы IA/UX

1. **Drill-down**: никаких инпутов на главном экране, только переходы.
2. **Прогрессивное раскрытие**: пользователь видит текущие значения справа, редактирование — внутри.
3. **Минимум CTA на одном экране**: не более 1–2 акцентных действий.
4. **Ясная иерархия**: сверху — профиль и подписка, снизу — выход/удаление.
5. **Мобильные паттерны**: строки с chevron, секции с заголовками, читаемые подписи.
6. **Focus-навигация**: при переходе к конкретной настройке экран автоматически проматывается к нужной секции и подсвечивает её на короткое время.

## 4. Новая структура (главный экран)

Порядок разделов и логика:

1. **Профиль** — карточка с аватаром, именем и email.
2. **Подписка** — отдельный визуально выделенный блок.
3. **Настройки ассистента** — стиль общения, обращение, таймер медитации.
4. **Конфиденциальность и данные** — память ассистента, политика, очистка.
5. **Приложение** — язык/локаль (смена), версия.
6. **Служебное** — ID пользователя, выход, удаление аккаунта.

## 5. Карта экранов и навигация

1. `/settings` — главный список настроек (без инпутов).
2. `/settings/profile` — редактирование профиля и безопасности.
3. `/settings/assistant` — тон/обращение/таймер.
4. `/privacy` — память и данные (фиксированный маршрут).
5. `/settings/language` — выбор языка/локали.
6. `/subscription` — управление подпиской.

## 6. Детализация экранов

### 6.1. Главный экран `/settings`

**Верх: карточка профиля**

- Аватар/инициалы + имя + email (серым).
- По тапу — переход на `/settings/profile`.

**Блок подписки**

- Glassmorphism карточка с названием плана, датой окончания и CTA «Управлять».
- Если подписки нет — CTA «Оформить».
- Лимиты минут — компактный прогресс-бар или мелкий текст.

**Секция: Настройки ассистента**

- Строки:
  - **Стиль общения** → справа «Нейтральный».
  - **Обращение** → справа «На “ты”».
  - **Таймер медитации** → справа «10 мин / Без таймера».
- Каждая строка ведёт на `/settings/assistant` (или в detail-экран, если разделить).

**Секция: Конфиденциальность**

- Строки:
  - **Память и данные** → `/privacy`.
  - **Политика конфиденциальности** → `/docs/privacy`.

**Секция: Приложение**

- **Язык** → текущий язык справа, по тапу — экран выбора `/settings/language`.

**Секция: Служебное**

- **ID пользователя** (копируемый по тапу, только для роли admin).
- **Выйти из аккаунта** (текстовая кнопка).
- **Удалить аккаунт** (destructive, красный текст).

### 6.2. Профиль и безопасность `/settings/profile`

Секции:

1. **Профиль**: имя, пол (editable).
2. **Email**: адрес (read-only), статус подтверждения, отправка кода, ввод кода.
3. **Пароль**: установить/изменить (как сейчас, с валидацией).

Поведение:

- Кнопка «Сохранить» только в секции профиля.
- Остальные секции сохраняются действием кнопок.
- Кнопка «Сохранить» неактивна по умолчанию, активируется только при отличиях от исходного состояния. Если пользователь вернул значения обратно — кнопка снова disable.

### 6.3. Настройки ассистента `/settings/assistant`

Секции:

1. **Стиль общения** — выбор тона (деликатный/нейтральный/воодушевляющий/решительный/требовательный).
2. **Обращение** — «ты/Вы».
3. **Таймер медитации по умолчанию** — off/10/20/30.

UX:

- Текущий выбор отображается крупнее.
- Опционально: все изменения сохраняются по кнопке «Сохранить» внизу, чтобы избежать лишних запросов.
- Кнопка «Сохранить» неактивна по умолчанию, активируется только при отличиях от исходного состояния. Если пользователь вернул значения обратно — кнопка снова disable.

### 6.4. Конфиденциальность `/privacy`

Сохраняем существующую структуру:

- **Память ИИ** (enablePreviousResponseId).
- **Память в приложении** (enableSummary).
- Инфо-блок с рекомендацией.
- Ссылка **«Как мы защищаем данные»**.
  > Примечание: кнопка **«Удалить все данные»** временно **убрана из UI**. Бэкенд-эндпоинт и логика остаются.

### 6.5. Язык `/settings/language`

Секции:

1. **Выбор языка**: RU/EN (радио-список или segmented).
2. **Подсказка**: язык влияет на интерфейс и тексты ассистента.

Поведение:

- Сохранение выбора обновляет `user.locale` и активную локаль i18n.
- При смене языка показываем toast «Язык обновлён».

## 9. UI-компоненты и стиль

- **Tailwind + shadcn-vue + Radix** (Tabs больше не используем).
- Строки — `ListItem` с chevron и вторичным текстом справа.
- Карточки — glassmorphism (`backdrop-blur`, `bg-white/10`).
- Иконки — Lucide (подчёркивают смысл секции).
- Минимальная высота тапа 44px, отступы 12–16px.

## 10. Анимации и эффекты

- Переходы между экранами: лёгкий fade + slide вверх.
- Внутри разделов — `staggered` появление строк (100–140ms).
- Переключатели памяти — плавная анимация блока описания (уже есть).
- Нажатие по строке: лёгкий scale/opacity feedback.
- При фокус-переходе секция подсвечивается (мягкий glow/подложка) на 2–3 секунды.

## 11. Состояния и ошибки

- Loading-состояния: skeleton для карточки профиля/подписки.
- Отдельный skeleton-шаблон для страницы настроек, повторяющий структуру основного списка (профиль, подписка, секции).
- Ошибка загрузки профиля: компактный блок + кнопка «Повторить».
- Ошибка сохранения: toast с текстом и логикой retry.

## 12. Данные и интеграции (текущие)

- `GET /api/user/me` → профиль.
- `PATCH /api/user/update` → имя/пол/локаль (добавить поддержку локали).
- `GET/PUT /api/settings/preferences` → addressing/tone.
- `PATCH /api/settings/chat` → настройки памяти (через store `chatSettings`).
- `POST /api/user/delete` → удаление аккаунта.
- `POST /api/user/data/purge` (или аналог) → «Удалить все данные» без удаления аккаунта (UI скрыт).

## 13. Приёмочные критерии

1. На `/settings` нет полей ввода и длинных описаний.
2. Все параметры редактируются на вложенных экранах.
3. Структура соответствует иерархии: профиль → ассистент → приватность → системное.
4. Все действия (сохранение, выход, удаление) доступны и не скрыты.
5. Язык можно менять через `/settings/language`, изменения применяются сразу.
6. «Удалить все данные» и «Удалить аккаунт» — разные действия, при этом «Удалить все данные» сейчас скрыта в UI.
7. ID пользователя отображается только для роли admin.
8. При навигации к конкретной настройке экран автопрокручивается и временно подсвечивает нужный блок.
9. UI соответствует glassmorphism и не ломается на iOS/Android/Web.
