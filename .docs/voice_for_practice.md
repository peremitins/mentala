Техническое задание: SOS-озвучка через готовые аудиофайлы

Цель

Добавить голосовые подсказки к SOS-практике "Сильное напряжение" (PMR) через предсгенерированные аудиофайлы, которые хранятся локально в `public` (аналогично звукам дыхательных практик).

1. Источник и формат аудио
   • Источник генерации: Yandex SpeechKit Text-to-Speech (ручная генерация вне приложения).
   • Формат: mp3.
   • Громкость: привести к единому уровню (например, -16 LUFS), чтобы не было скачков между треками.
   • Длительность фраз: короткие клипы 1-3 секунды.
   • Качество: 64 kbps достаточно для голоса.

2. Набор аудиофраз для практики "Сильное напряжение" (PMR)

Список ключей (минимальный набор для MVP), для каждого ключа 2 версии: informal / formal:

**Текущие ключи в `sosTemplates.ts`:**
• `clench` — "Сильно сожми кулаки" / "Сильно сожмите кулаки"
• `release` — "Длинный выдох и полностью расслабь кисти" / "Длинный выдох и полностью расслабьте кисти"

**Дополнительные ключи для полноценной озвучки (добавить в sosTemplates.ts):**
• `intro` — вводная фраза перед началом практики
• `finish` — завершение всей практики

Структура файлов:

```
public/sos/tension/informal/clench.mp3
public/sos/tension/informal/release.mp3
public/sos/tension/formal/clench.mp3
public/sos/tension/formal/release.mp3
...
```

Тексты для озвучки берём из `app/lib/sosTemplates.ts`.

3. Хостинг и пути
   • Разместить файлы локально в `public/sos/tension/{addressing}/{key}.mp3`
   • БЕЗ хешей в именах (как у breath sounds), для упрощения
   • Примеры путей:

   - `/sos/tension/informal/clench.mp3`
   - `/sos/tension/formal/release.mp3`

4. Контракт в коде

Создать файл `app/lib/sosPracticeAudio.ts` (аналогично `breathPracticeAudio.ts`):

```typescript
export type SosTensionAudioKey = 'intro' | 'clench' | 'release' | 'finish';
export type SosAddressing = 'informal' | 'formal';

export const SOS_TENSION_AUDIO: Record<
  SosAddressing,
  Record<SosTensionAudioKey, string>
> = {
  informal: {
    intro: '/sos/tension/informal/intro.mp3',
    clench: '/sos/tension/informal/clench.mp3',
    release: '/sos/tension/informal/release.mp3',
    finish: '/sos/tension/informal/finish.mp3',
  },
  formal: {
    intro: '/sos/tension/formal/intro.mp3',
    clench: '/sos/tension/formal/clench.mp3',
    release: '/sos/tension/formal/release.mp3',
    finish: '/sos/tension/formal/finish.mp3',
  },
};
```

5. Логика воспроизведения в практике
   • **Настройка**: `voiceEnabled` (по умолчанию `false`)

   - Хранится в Capacitor Preferences: `sos.tension.voice_enabled`
   - Отдельная настройка для SOS (не общая с дыхательными практиками)
     • **При смене фазы** (clench → release):
   - Если `voiceEnabled === true`, проиграть соответствующий клип
   - Таймер практики продолжает работать параллельно (голос не блокирует)
     • **При ошибке загрузки**:
   - Практика не ломается
   - Тихо продолжаем без звука
   - Опционально: показать toast "Голос недоступен"

6. Прелоад
   • При старте практики "Сильное напряжение" предзагрузить все клипы для текущего `addressing`
   • Использовать `new Audio()` и вызывать `.load()` для каждого
   • Кешировать экземпляры Audio в Map для переиспользования
   • Прелоад выполняется только если `voiceEnabled === true`

7. Требования к UX
   • **Переключатель "Голос"** на экране SOS-практики "Сильное напряжение"
   • Располагается рядом с кнопкой "Прервать и вернуться"
   • Состояние сохраняется в Preferences
   • При выключенном голосе прелоад не выполняется

8. Расширение sosTemplates.ts

Добавить недостающие тексты для TTS:

```typescript
export const SOS_TENSION_VOICE_TEXTS = {
  intro: {
    informal: 'Начинаем. Приготовься',
    formal: 'Начинаем. Приготовьтесь',
  },
  clench: {
    informal: 'Медленный вдох, сильно сожми кулаки и удерживай напряжение',
    formal: 'Медленный вдох, сильно сожмите кулаки и удерживайте напряжение',
  },
  release: {
    // Примечание: "Медленный выдох" звучит мягче чем "Длинный" для русского языка
    // Два действия в одной фразе - это компромисс для MVP, но для TTS приемлемо
    informal: 'Медленный выдох и полностью расслабь кисти',
    formal: 'Медленный выдох и полностью расслабьте кисти',
  },
  finish: {
    informal: 'Практика завершена',
    formal: 'Практика завершена',
  },
} as const;
```

**Стилистические замечания для будущих итераций:**

**SOS_TENSION_INSTRUCTIONS.release:**

- Текущая версия: "Медленный выдох и полностью расслабь кисти"
- Два действия в одной фразе - это компромисс для MVP
- В будущем можно разбить на два отдельных аудиоключа для более четкой инструкции

**SOS_GROUNDING_STEPS (5-4-3-2-1):**
Сейчас используются разные глаголы (найди, назови, отметь, определи, заметь), что создает смешение стилей. Для будущих версий рекомендуется:

- Унифицировать глаголы для единого стиля
- Шаг 3: "отметь" → "назови" (как в шаге 1)
- Шаг 4: "Определи" → "Почувствуй" или "Замечай" (мягче)
- Шаг 4: "или их отсутствие" можно упростить

Для MVP текущие тексты допустимы, они работают и не создают критичных проблем.

9. Acceptance criteria
   • При включённом голосе клипы проигрываются синхронно со сменой фаз
   • При отсутствии файлов или плохой сети практика работает без голоса
   • Нет скачков громкости между клипами
   • Одинаковое воспроизведение на Web, iOS и Android
   • Настройка `voiceEnabled` сохраняется между сессиями
   • Прелоад выполняется только при включенном голосе

10. UX/UI стандартизация экрана "Сильное напряжение"

Цель: унифицировать экран PMR в SOS с UX-паттерном `BreathPracticePlayer` (единая визуальная модель, единая нижняя панель, единый оверлей подготовки).

10.1 Общий layout
• Экран `tension-practice` использует ту же композицию, что и дыхательные практики:

- контентный центр (инструкция + таймер/сфера),
- фиксированная нижняя панель управления,
- кнопка «Назад» в хедере SOS (как в PageHeader) для возврата к выбору техники.
  • Нижняя панель не должна сдвигаться при появлении оверлеев/диалогов.
  • Для перекрывающих слоев использовать тот же подход, что в `BreathPracticePlayer` (Teleport + fixed + корректный z-index).

  10.2 Нижняя панель управления (как в дыхании)
  • Панель управления визуально и структурно повторяет `BreathPracticePlayer`:

- прогресс-бар с оставшимся временем,
- кнопки управления с теми же размерами/стилем.
  • В PMR-сценарии минимальный набор действий:
- `Стоп` (остановить практику),
- `Пауза/Продолжить`.
  • Если действие "Назад/Вперёд" не применимо к PMR, кнопки не показывать.

  10.3 Навигация назад
  • В хедере SOS при открытой технике отображается кнопка «Назад» (стиль как в PageHeader: Button variant ghost, IconChevronLeft).
  • Кнопка возвращает: с panic-techniques → select; с panic-grounding/panic-breathing → panic-techniques; с tension-practice/finish → select.

  10.4 Настройки практики (modal)
  • Модалка настроек должна быть унифицирована с `BreathPracticePlayer`.
  • В модалке добавить отдельный пункт:

- `Голос` — озвучка голосовыми фразами PMR (`intro/clench/release/finish`).
  • Сохранить и явно развести два переключателя:
- `Голос` = TTS-фразы PMR,
- `Звуковые эффекты` = короткие сигналы (по аналогии inhale/exhale в дыхании).
  • Состояния переключателей сохраняются локально между сессиями.

  10.5 Оверлей подготовки
  • На старте PMR показать оверлей обратного отсчёта в том же стиле, что у дыхательных практик.
  • Оверлей не должен ломать layout и не должен останавливать нижнюю панель.
  • При включенном голосе после оверлея соблюдается текущая логика синхронизации `intro` и старта цикла.

  10.6 Ограничения и совместимость
  • Без `dark:`-классов; использовать токены/переменные текущей темы.
  • Кроссплатформенно: Web + iOS + Android.
  • Безопасные проверки браузерных API (`typeof Audio !== 'undefined'`, `isDocumentAvailable()`).

11. Acceptance criteria (UX/UI)
    • Экран PMR визуально совпадает по структуре с `BreathPracticePlayer`.
    • Нижняя панель управления идентична по UX-поведению (fixed, без скачков).
    • Кнопка «Назад» в хедере всегда доступна на экранах техник.
    • В настройках есть отдельный пункт `Голос` и отдельный пункт `Звуковые эффекты`.
    • Оверлей подготовки отображается и скрывается без сдвига UI.
    • Переключение `Голос` не останавливает технику и не сбрасывает таймер.

12. Утверждённые решения (после уточнений)

• `Звуковые эффекты` в PMR: пока используем существующие сигналы `inhale/exhale`.
• Кнопка `Настройки`: обязательна в нижней панели управления.
• При нажатии `Настройки`: открывается модалка практически как в дыхательных практиках, с дополнительным пунктом `Голос`.
• Оверлей подготовки: такой же, как в дыхательных практиках.
• Оверлей подготовки показывается каждый раз при запуске/повторе практики.
• Длительность PMR по умолчанию: 2 минуты.
