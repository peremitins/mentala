# Mentala — Продуктовый документ

## Описание
Мультиплатформенное приложение для психологической самопомощи и отказа от вредных привычек. Web/PWA/iOS/Android через Capacitor.

## Ключевые особенности
- Персональная поддержка на основе ИИ (текст/голос)
- Трекеры привычек, геймификация (стрики, бейджи)
- Персонализация (возраст, цели, привычки, RU/EN)
- Безопасность и приватность по умолчанию

## Фичи MVP
1. Онбординг (анкета + цели)
2. Чат с ИИ (RU/EN) + голос (TTS/STT)
3. Трекер привычек + статистика
4. SOS-экран (самопомощь + контакты)
5. Подписки (web + IAP)

## Безопасность и этика
- Safety by design: фильтрация кризисных запросов → SOS и ресурсы помощи
- Privacy by default: история не сохраняется без согласия
- Шифрование на диске и в транзите, минимизация PII
- 16+ (или по локальному праву)

## Монетизация
- Подписка: Basic (0₽) / PRO (399₽) / Premium (899₽)
- Web: YooKassa, iOS: StoreKit 2

## Нефункциональные требования
- P95 < 200ms, uptime 99.9%
- Адаптив: от 320px, iPhone 13+ и Android 8+
- a11y: фокус, контраст, ARIA
