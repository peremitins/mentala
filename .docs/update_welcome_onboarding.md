Техническое задание

Доработка онбординга Mentala

1. Цель

Сделать онбординг более тёплым, понятным и персонализированным.

Онбординг должен:
• вызывать доверие с первого экрана
• объяснять ценность Mentala
• собирать только действительно полезные данные
• настраивать опыт под пользователя
• выглядеть не как форма регистрации, а как мягкое введение в продукт

⸻

2. Текущее состояние

Сейчас в онбординге есть шаги: 1. приветствие 2. имя 3. пол 4. возраст 5. стиль общения 6. завершение

Проблемы текущей структуры:
• слишком мало эмоционального контекста
• нет вопроса, зачем пользователь пришёл в приложение
• нет вопроса о цели пользователя
• тексты местами звучат слишком сухо
• онбординг ощущается как анкета, а не как персональная настройка поддержки

5. Логика шагов

Рекомендуемый порядок шагов: 1. приветствие 2. имя 3. причина прихода 4. желаемый результат 5. возраст 6. пол 7. стиль общения 8. завершение

Почему именно так:
• сначала формируется доверие
• потом идёт лёгкий личный вопрос
• затем собирается главный контекст пользователя
• только после этого спрашиваются технические данные
• ближе к концу настраивается тон общения

Это воспринимается намного естественнее, чем когда после имени сразу спрашивают пол и возраст.

⸻

6. Что важно изменить в текстах

Все тексты онбординга должны быть:
• мягкими
• короткими
• человечными
• без канцелярита
• без ощущения анкеты
• без излишне рекламных обещаний

Нужно избегать формулировок в стиле:
• давайте быстро настроим приложение
• выберите параметры профиля
• завершите регистрацию

Нужен тон:
• спокойный
• бережный
• простой
• поддерживающий

⸻

7. Что можно отложить

Пока не обязательно добавлять:
• длинные объяснения
• несколько экранов с преимуществами продукта
• сложную сегментацию
• выбор нескольких целей сразу
• дополнительные психологические тесты

Для первой итерации достаточно сделать короткий, но более осмысленный онбординг.

⸻

8. Итоговое решение для первой итерации

В первой итерации рекомендуется:
• оставить приветственный экран
• оставить имя
• добавить шаг “Что привело вас в Mentala?”
• добавить шаг “Чего вы хотите достичь?”
• оставить возраст
• оставить пол, но сделать его нейтральнее
• переписать шаг со стилем общения
• переписать финальный экран

Итог: онбординг станет заметно сильнее без лишнего усложнения.
