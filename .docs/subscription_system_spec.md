# 🧠 Mentai — Система подписок и гибкой тарификации (Tech Spec / Тестовое задание)

## 📘 Общая идея

**Mentai** — это кроссплатформенное приложение для ментального здоровья, объединяющее:

- персональные уведомления,
- AI-чат (GPT/DeepSeek/аналог),
- реалистичный аватар с липсингом (Simli API),
- систему гибких тарифных планов.

Приложение должно позволять пользователю **выбрать оптимальный план** и **гибко настраивать собственный режим занятий**.  
Система должна автоматически **пересчитывать стоимость**, исходя из частоты, длительности и наличия аватара.

---

## 🎯 Цель

Реализовать **унифицированную систему подписок** с поддержкой:

1. Трёх фиксированных тарифов: **Trial / PRO / Premium**
2. Одного гибкого тарифа: **Custom Plan**
3. Автоматического пересчёта стоимости при изменении настроек пользователя
4. Гибкой интеграции с API оплаты (Google Play, App Store, Stripe, YooKassa и др.)
5. Возможности легко редактировать цены и лимиты без изменения кода

## 🧩 Структура тарифов

| Тариф       |             Стоимость | Возможности                                        | Лимиты                             |
| ----------- | --------------------: | -------------------------------------------------- | ---------------------------------- |
| **Trial**   |          0 ₽ (7 дней) | Пробный доступ к AI-чату без аватара               | 2 сессии × 30 мин / нед            |
| **PRO**     |           399 ₽ / мес | Чат с AI (GPT/DeepSeek), уведомления, отчёты       | 2 сессии × 50 мин / нед            |
| **Premium** |           799 ₽ / мес | Чат с AI + Аватар (Simli), расширенные уведомления | 2 сессии × 50 мин / нед            |
| **Custom**  | Автоматический расчёт | Гибкая настройка частоты, длительности и аватара   | От 1 до 7 раз в неделю × 10–60 мин |

## ⚙️ Настраиваемые параметры (Custom Plan)

| Параметр                  | Тип     | Описание                                       | Диапазон / Варианты    | Значение по умолчанию |
| ------------------------- | ------- | ---------------------------------------------- | ---------------------- | --------------------- |
| `sessions_per_week`       | number  | Количество занятий в неделю                    | 1–7                    | 2                     |
| `minutes_per_session`     | number  | Длительность одной сессии (градация по 10 мин) | 10, 20, 30, 40, 50, 60 | 50                    |
| `avatar_enabled`          | boolean | Включить реалистичного аватара (Simli)         | ✅ / ❌                | false                 |
| `price_per_minute_gpt`    | number  | Стоимость минуты GPT-сессии                    | 0.66 ₽                 | —                     |
| `price_per_minute_avatar` | number  | Стоимость минуты Simli                         | 0.9 ₽                  | —                     |
| `base_price_pro`          | number  | Базовая цена PRO-плана                         | 399 ₽                  | —                     |
| `base_price_premium`      | number  | Базовая цена Premium-плана                     | 799 ₽                  | —                     |

## 🧮 Формула расчёта стоимости (Custom Plan)

```ts
total_minutes_per_month = sessions_per_week * minutes_per_session * 4;

total_price =
  price_per_minute_gpt * total_minutes_per_month +
  (avatar_enabled ? price_per_minute_avatar * total_minutes_per_month : 0) +
  base_price_pro;
```

> 💡 Пример:
> Пользователь выбрал 5 занятий в неделю по 40 мин с аватаром:  
> `total_minutes_per_month = 5 × 40 × 4 = 800 мин`  
> `price = (0.66 + 0.9) × 800 + 399 = 1248 + 399 = 1647 ₽ / мес`

## 🧱 Архитектура данных

### Модель `SubscriptionPlan`

```ts
interface SubscriptionPlan {
  id: string;
  name: 'trial' | 'pro' | 'premium' | 'custom';
  basePrice: number;
  sessionsPerWeek: number;
  minutesPerSession: number;
  avatarEnabled: boolean;
  pricePerMinuteGPT: number;
  pricePerMinuteAvatar: number;
  totalPrice: number;
  startDate: string;
  endDate?: string;
  isActive: boolean;
}
```

### Модель `UserSubscription`

```ts
interface UserSubscription {
  userId: string;
  planId: string;
  customConfig?: Partial<SubscriptionPlan>;
  paymentStatus: 'active' | 'expired' | 'pending';
  renewalDate?: string;
}
```

## 🛠️ API (черновая схема)

| Метод   | Endpoint                             | Описание                                                |
| ------- | ------------------------------------ | ------------------------------------------------------- |
| `GET`   | `/api/subscriptions/plans`           | Получить список всех доступных тарифов                  |
| `POST`  | `/api/subscriptions/custom/calc`     | Рассчитать стоимость кастомного плана по входным данным |
| `POST`  | `/api/subscriptions/custom/activate` | Создать/обновить подписку пользователя                  |
| `PATCH` | `/api/subscriptions/:id`             | Изменить настройки активного тарифа                     |
| `GET`   | `/api/subscriptions/user/:userId`    | Получить активную подписку пользователя                 |

## 💾 Логика работы (Backend)

1. Пользователь выбирает тариф → `/plans` → отображается карточка.
2. При выборе **Custom Plan**:
   - открывается форма настройки (слайдеры и тумблер);
   - при каждом изменении параметра вызывается `/custom/calc`;
   - API возвращает пересчитанную стоимость в реальном времени.
3. После подтверждения:
   - создаётся запись `UserSubscription`;
   - активируется план с указанными параметрами и ценой;
   - дата окончания подписки рассчитывается автоматически (30 дней).
4. Оплата проводится через соответствующий платёжный шлюз (Google / Apple / Stripe / YooKassa).
5. История подписок хранится для аналитики и лояльности.

## 📅 Trial-логика

- Длительность: **7 дней**
- Активируется автоматически при первой регистрации
- Без ввода карты
- Содержит ограниченные функции (только чат, без аватара)
- После окончания — автопредложение перейти на **PRO**

---

## 📈 Масштабирование

- Возможность добавления новых тарифов в JSON-конфиг (`plans.config.ts`)
- Поддержка опций **“докупить минуты”** (100/200/500 мин)
- Возможность интеграции SOS-модулей в будущем (через флаг `sos_enabled`)
- Поддержка ежемесячных и годовых подписок (годовая со скидкой 25%)
