## 📱 Как установить Android Studio (macOS)

### Вариант 1: Через Homebrew (рекомендуется)

```bash
# Установка через Homebrew
brew install --cask android-studio

# После установки откройте Android Studio и выполните настройку
open -a "Android Studio"
```

### Вариант 2: Ручная установка

1. Скачайте Android Studio: https://developer.android.com/studio
2. Откройте `.dmg` файл и перетащите в Applications
3. Запустите Android Studio и выберите "Standard" установку
4. Дождитесь загрузки Android SDK

## 🚀 Запуск приложения

### ⚠️ ВАЖНО: Запусти dev-сервер

Перед запуском мобильного приложения **обязательно** запусти dev-сервер:

```bash
# В отдельном терминале запусти сервер
pnpm dev
```

Сервер должен запуститься на `http://0.0.0.0:3000` (слушает на всех интерфейсах)

### Шаг 1: Синхронизация с Capacitor

```bash
# Для эмулятора:
pnpm run cap:sync:emulator

# ИЛИ для реального устройства:
pnpm run cap:sync:device

# Это автоматически настроит правильные URL и синхронизирует проект
```

### Шаг 2: Открытие в Android Studio

```bash
pnpm run cap:open:android
```

### Шаг 3: Создание эмулятора (если нужно)

1. В Android Studio: **Tools** → **Device Manager**
2. Нажмите **Create Device**
3. Выберите **Pixel 5** или любое другое устройство
4. Выберите системный образ **API 34** или выше
5. Нажмите **Finish**

### Шаг 4: Сборка и запуск

#### Способ 1: Через меню Android Studio

1. **Закрой контекстное меню**, если оно открыто (нажми `Esc`)
2. **Посмотри в самый верх** окна Android Studio — там строка меню:
   - **Build** → **Clean Project**
   - **Build** → **Rebuild Project**
   - **Run** → **Run app** (▶️)
3. Или используй **зелёную кнопку ▶️** в верхней панели инструментов

#### Способ 2: Через горячие клавиши

- **macOS**: `Cmd + F9` (Make Project), `Shift + F10` (Run)
- **Windows/Linux**: `Ctrl + F9` (Make Project), `Shift + F10` (Run)

#### Способ 3: Через Gradle панель (справа)

1. Открой **Gradle** панель справа (иконка слоёв или **View** → **Tool Windows** → **Gradle**)
2. Раскрой **app** → **Tasks** → **build**
3. Дважды кликни на **clean**, затем на **build** или **installDebug**

#### Способ 4: Через терминал (самый надёжный) ⭐

```bash
cd android
./gradlew clean
./gradlew installDebug
```

Для запуска на конкретном устройстве:

```bash
cd android
./gradlew installDebug -PtargetDevice=<device_id>
```

## 🐛 Если что-то не работает

### Ошибка "This app requires a WebView to work"

**Причина**: Dev-сервер не запущен или Capacitor не может подключиться к серверу.

**Решение**:

1. **Убедись, что dev-сервер запущен**:
   ```bash
   # В отдельном терминале:
   pnpm dev
   ```
2. **Проверь, что сервер доступен**:

   ```bash
   curl http://localhost:3000
   # Должен вернуть HTML
   ```

3. **Синхронизируй конфиг**:

   ```bash
   # Для эмулятора:
   pnpm run cap:sync:emulator

   # ИЛИ для реального устройства:
   pnpm run cap:sync:device
   ```

4. **Пересобери приложение**:
   ```bash
   cd android
   ./gradlew clean installDebug
   ```

### Черный экран после запуска

**Причина**: Приложение пытается загрузить статические файлы, но они не загружаются правильно.

**Решение**: Используй dev-сервер для разработки:

```bash
# 1. Запусти dev-сервер в отдельном терминале
pnpm dev

# 2. Для эмулятора:
pnpm run cap:sync:emulator

# ИЛИ для реального устройства:
pnpm run cap:sync:device

# 3. Пересобери и запусти приложение
cd android && ./gradlew clean installDebug
```

### Запросы не проходят / Failed to fetch / Mixed Content

1. **Для разработки** (рекомендуется):

   - Запусти dev-сервер: `pnpm dev`
   - Используй `pnpm run cap:sync:emulator` (для эмулятора) или `pnpm run cap:sync:device` (для устройства)
   - Это автоматически настроит правильные URL

2. **Для production сборки**:
   - IP больше не нужно указывать вручную - используются относительные пути
   - Для dev используй скрипты: `pnpm run cap:sync:emulator` (эмулятор) или `pnpm run cap:sync:device` (устройство)
   - После изменения выполни: `pnpm generate && pnpm cap:sync`

### Микрофон на эмуляторе

**⚠️ ВАЖНО:** На эмуляторе микрофон может не работать по умолчанию. Если видите зеленую точку (запись идет), но текст не появляется — микрофон не настроен правильно.

**Как настроить микрофон в эмуляторе:**

1. **В Android Studio — AVD Manager**:

   - Открой **Tools** → **Device Manager** (или **AVD Manager** в старых версиях)
   - Выбери свой эмулятор и нажми **Edit** (карандаш)
   - В разделе **Advanced Settings** найди опцию **Microphone**
   - Установи значение **Enabled** (включено)
   - Сохрани изменения и перезапусти эмулятор

2. **Проверка настройки микрофона в системе**:

   - **macOS**: Системные настройки → Безопасность и конфиденциальность → Конфиденциальность → Микрофон → Разрешить доступ для Android Studio
   - **Windows**: Параметры → Конфиденциальность → Микрофон → Разрешить доступ для Android Studio

3. **В эмуляторе (разрешения приложения)**:

   - Настройки → Для разработчиков → Разрешения приложений
   - Или: Настройки → Приложения → Mentala → Разрешения
   - Включи **Микрофон**

4. **Проверка работы микрофона**:

   - Запусти стандартное приложение **Диктофон** на эмуляторе
   - Попробуй записать звук
   - Если не работает — проблема в настройках эмулятора

**Если микрофон всё равно не работает:**

Эмулятор Android Studio часто не поддерживает запись звука корректно. Для тестирования голосового ввода рекомендуется использовать **реальное устройство**, где микрофон гарантированно работает.

### Другие проблемы

- **Android Studio не видит SDK**: Проверьте `ANDROID_HOME` в настройках Android Studio
- **Эмулятор не запускается**: Убедитесь, что установлен HAXM (Hardware Acceleration)
- **Уведомления не работают**: Проверьте разрешения в настройках эмулятора/устройства
- **Проект не собирается**: Попробуйте `cd android && ./gradlew clean`
